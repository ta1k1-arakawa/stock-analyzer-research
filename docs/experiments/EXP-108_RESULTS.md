## 抽出方法と監査

- 抽出は決定的な HTML 表パーサ（`experiments/exp108_yenbeta.py` 実行系とは別に構築した抽出系）で全件処理し、再ゲート（R11-5）の LLM 精読による真値 60件と照合して **60/60 一致**（ステータス・値とも）を確認したうえで本実行に用いた。
- 表の優先順位は登録どおり（①地域別ブロック（省略・ゼロ注記を含む）→ ②セグメント注記内の地域区分 → ③使用不能）。競合時の解決として、見出し付き地域ブロック（「地域別に関する情報」等）を収益分解表より優先する規則と、旧式有報で横に分割された表の断片結合を実装した。どちらもゲート精読の60件一致を維持したまま適用している。
- 打ち切りの同値表現: 「本邦以外／海外の売上が10%未満のため省略」は「本邦90%超のため省略」と同条件の裏側の表現として censored（0.05）に数えた。
- 手作業で精読し手入力したものが48件ある（競合の裁定、および会社固有の形式: 6269 三井海洋開発・6659 は地域表に本邦行がなく開示地域の合計が総額と一致するため本邦=0 として処理、7211 三菱自動車の売上高＋収益分解の合算表、7599・7637・262A・6090・7224 の地域セグメント／分解表、4565 は本邦値が △22（マイナス）で ovs=1.0012 を計算どおり採用、等）。全て `overseas_share.csv` の元値（japan_sales / total_sales）で監査可能。
- 使用不能 102件の内訳: 地域開示自体がない（4689 LINEヤフー、7354、7413）、上限を示さない省略（「大部分」「僅少」「重要性が乏しい」: 7199、7616、7893、8253、2480、6543、6037、2120 の初期2件）、販売先の把握困難（3903 gumi）、拠点所在地のみの記述（7509、8715）、単一セグメント内訳のみ（6763）、単一国10%注記のみ（3627）。

## 診断

- ブック内で ovs が付く銘柄は中央値で前半118/日・後半123/日（有効銘柄 約129/日）——脚はほぼ全面に効いており、被覆不足による失敗ではない。
- それでも DD は前半 −23.76%→−25.06%、後半 −16.91%→−20.82% と両半期で深くなった。ステージ0の日次スプレッド（−0.69pt/日）は、A のブックのDD局面が「指数の暴落日」だけでは構成されないこと（ファクターの冬型の下落では国内寄りロングも同様に売られる）、1/3ウェイトの脚が composite＋モメンタムの銘柄選択を薄め（前半利益はマイナス化）、20日保有・2日リバランスのトランシェ構造では同日ベータ差を回転で回収できないこと、と整合的である。

## 解釈

前提（暴落日に海外比率の高い銘柄が余分に下がる）は正しいが、凍結した構成（国内比率ランクを 1/3 ウェイトで A のスコアに混ぜる）ではポートフォリオ水準のDD防御にならず、改善を主張した次元そのもので両半期とも悪化した。登録基準どおり不採用とし、円ベータの A スコア脚としての方向は閉じる。ステージ0の事実はリスク知識として記録に留める（スコアには使わない）。
