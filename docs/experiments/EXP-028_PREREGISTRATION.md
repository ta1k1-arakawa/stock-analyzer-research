# EXP-028 事前登録：A の最小分散「構築」（銘柄選択は不変、ウェイトだけ最適化）

状態: 計画（未実行）

## 背景・仮説

文献探索（2026-10-31）の第5案。MSCI Japan Minimum Volatility は長期で母集団指数より最大 DD が浅い（10年で 39.7% vs 53.2%）。EXP-013 のボラティリティ・オーバーレイ（本全体の露出を縮める）とは別物として、本実験は**銘柄選択を A のまま固定し、選ばれた20銘柄への配分ウェイトだけを最小分散化**する。選択（＝スコアへの露出）を変えないため、A の利益の源泉を保ったまま、相関の高い銘柄への集中による DD を浅くできる可能性がある。

## 方法（すべてこの事前登録で固定する）

- エンジン: EXP-013 の simulate2 を複製し、購入時の等分をウェイト配分に置き換えた simulate_w を使う。**検証ゲート**: ウェイトを等分に固定した simulate_w が A を完全再現すること（最大差分 0 近傍）を、本体の数値より前に確認する。再現しなければ実行を中止し報告する
- ウェイト計算（トランシェのリバランスごと、ロング・ショート各側で独立に）:
  - 選択された銘柄群について、リバランス日の前営業日までの直近 120 営業日の日次リターン（終値ベース）から標本共分散 Σ を作る
  - Σ_shrunk = 0.5·Σ + 0.5·diag(Σ)（縮小）
  - w* = Σ_shrunk⁻¹1 を正規化した最小分散ウェイトとし、[0.02, 0.10] にクリップ→再正規化を2回繰り返す
  - 選択銘柄のいずれかが窓内に有効リターン 60 本未満、または行列が解けない場合は、その側・そのリバランスは等ウェイトにフォールバックする
- ロングは tranche の現金を w で配分、ショートは想定元本を w で配分する。それ以外（選択、上位/下位20、1.0/0.5、保有20日、費用）は A と同一
- バリアントは1本のみ（A_mv）。比較対象は A（S も併記）。期間・費用は従来通り

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- 最小分散ウェイトは低ボラ銘柄への偏りを生み、A の選択が持つモメンタム的な勢いを弱める可能性がある（MSCI の最小分散はロングオンリー指数であり、LS ブックでの外挿は未検証）
- 共分散の推定誤差は 120 日窓でも大きく、縮小とクリップで緩和するが消えない
- 側ごとに独立に最小化するため、ブック全体の分散最小化にはならない（設計として明示）
- EXP-013（ボラ系の2変種）が失敗している近縁領域である。ただし本案は露出の縮小でもスコアの加工でもなく「配分」だけの変更である点が異なる
