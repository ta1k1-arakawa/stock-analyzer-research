# EXP-117 事前登録: 来期上期（H1）減益ガイダンス旗の追加（NxFNp2Q、AGN 土台対比）

登録日: 2026-11-10（本書を実行前に push し、その時点で確定する）。常駐指示（2026-11-08）に基づき、通過した場合はユーザーの追加承認なしにフォワード・ペーパー統合まで進める。ライブA・実弾Vは変更しない。

## 仮説

EXP-114（来期純利益の減益ガイダンスによるロング・ペナルティ）は標準3基準を通過し、ペーパー AGN として再演でも条件 (i) を満たした（EXP-115）。同じ FY 開示には来期の**上期（2Q累計）**純利益予想（NxFNp2Q）も載っているが、ガイダンス系の採掘はこれまで通期ライン（NxFNp／NxFOP／NxFSales／含意マージン）しか測っておらず、H1 ラインは未測定だった。H1 減益旗（NxFNp2Q ≤ 0.90 × 当期上期 NP）は記述段階で通期 NP 旗と同等の強さを持ち、決定的に、**通期 NP・OP 両旗を除いた増分（260件）が両半期ともマイナスで残る**——これは増分が消滅して落ちた EXP-116（OP のみ 76件・前半 −1.55%）や売上・マージン拡張（両旗除外 45件で消滅）と異なる形である。本実験は **AGN を土台**とし、旗を「通期 NP 旗 ∪ H1 NP 旗」へ拡張したときに AGN 対比で改善が残るかを判定する。合成・拡張は土台対比で判定する（第10弾の設計ルール、「合成は土台対比で落ちる」先例が3回あることを踏まえた登録であり、A 対比での近傍亜種の量産ではない）。

前提となる記述ゲート（2026-11-10 23:45ラン「来期ガイダンスの H1 ライン」）は通過済み。J-Quants fins（306 銘柄、FY 重複除去後 2,925 件）でイベントスタディ（TOPIX 対比超過、終値→終値、DiscDate の終値を起点。従来の採掘と同一の慣行）を実施した結果は下記のとおり。

## 記述ゲートの結果

- **H1 NP 成長率（NxFNp2Q／当期上期 NP − 1、1,335件）**: 五分位は単調（Q1 −3.55% → Q5 +2.17%、20日）。Q5−Q1 は 20日で前半 +5.03pp／後半 +6.39pp、60日で +9.37／+8.48pp と通期 NP 版と同等以上の広がり。通期 nx_np_growth との生相関は 0.054 と低く（分母の半期／通期の違いによる）、同一情報の言い換えではない。
- **H1 NP 減益旗（NxFNp2Q ≤ 0.90 × 上期 NP、597件・180銘柄）**: 20日平均 −3.44%（中央値 −3.93%）、前半 −3.22%（中央値 −3.41%）／後半 −3.65%（中央値 −4.50%）、60日 −3.11%。**R1（両半期同符号）・R2（20日と60日で同方向）通過**。旗内の H1 成長率中央値は −30.6%（深い減益予告が中心）。
- **用量反応**: ≤0.80× の旗（443件）は 20日 −3.73%（前半 −3.32%／後半 −4.10%）と ≤0.90× より強く、閾値方向に単調。
- **重なりと増分の監査（R3）**: 通期 NP 旗と両方 319件、OP 旗と両方 195件（両方同時 177件）、**H1 のみ（両旗とも該当せず）260件・134銘柄**。
  - **H1 のみ（260件）**: 20日 −2.03%（中央値 −3.25%）、前半 −2.14%（中央値 −2.78%）／後半 −1.94%（中央値 −3.47%）、60日 −1.99%。両半期・両ホライズンで符号が残る——これが本実験の増分の実体であり、EXP-116 の OP のみ増分（76件）より標本が3倍以上厚い。
  - 通期 NP 旗を除いた H1 旗全体（278件）でも 20日 −2.13%（前半 −2.12%／後半 −2.13%）と対称。
- **暦年別**: 2017–2025 の9年すべてで平均マイナス（−0.98%〜−6.23%）。2026年は +1.43%（39件）だが、これは FY2026 開示分のみの部分年で標本が小さく、判定は半期分割（R1）を正とする。
- **集中監査**: 上位3銘柄（7150・8558・3431）を除いても 20日 −3.43% と不変。
- **ホライズン分解（留保は EXP-114 と同型）**: 20日効果 −3.44% のうち 5日目までに −2.60%（約76%）が生じる。翌日寄付執行の簿が捕捉できるのは一部のみであり、判定はブックテストの結果のみによる。なお EXP-114 も同型の留保（5日で約75%）を抱えたまま通過した。
- **同レンズの他ラインは登録しない**: H1 OP 減益旗（NxFOP2Q ≤ 0.90 × 上期 OP、453件）も 20日 −4.07%（前半 −4.06%／後半 −4.07%）と記述上は強いが、NP ラインと同時登録すると複合ライン化して EXP-116 型の失敗形状に近づくため、本登録では NP ライン単独に固定する。H1 OP は結果文書で参考記録するに留める。

## 信号の固定

- **ソース**: J-Quants fins（`~/workspace/cache/jquants_exp002/fins/*.json`、306 銘柄分）。新規取得・追加支出は行わない。フォワード統合時は EXP-115 の `forward/guidance_events.csv` に H1 ラインの列を拡張する（統合は通過後の工程）。
- **フラグの定義**: 銘柄の FY 開示（(code, CurFYEn) ごとに NP 非欠測の最終 DiscDate 行を採用し、NxFNp・NxFNp2Q が欠測の場合は同一グループ内の最新の非欠測行で補完する——EXP-114 の実行で確定した補完手続きと同一）について、次のいずれかを満たせば減益ガイダンス・フラグ（拡張旗）を立てる。
  - 通期: **NxFNp ≤ 0.90 × NP**（NP・NxFNp ともに正で非欠測の場合のみ）——AGN の既存旗。
  - H1: **NxFNp2Q ≤ 0.90 × 上期 NP**。上期 NP は同一 (code, CurFYEn) の 2Q 開示行の NP（累計値、DiscDate が最後の行を採用）。NxFNp2Q・上期 NP ともに正で非欠測の場合のみ判定する。
  ポイント・イン・タイムは FY 開示の DiscDate。FY 以外の開示では旗を立てない。
- **有効期間**: フラグは DiscDate の**翌営業日から起算して 60 営業日**有効（EXP-114 と同一）。翌年度の FY 開示で再判定し、条件を満たせば延長、満たさなければその開示で失効する。
- **効果**: フラグ有効期間中の銘柄を**土台 AGN のロング側で −0.10 ティルト**する。AGN は既に通期 NP 旗に −0.10 を課しているため、本実験の実質的な変更は H1 のみ旗の銘柄への新規 −0.10 のみである。**両旗とも該当する銘柄でも −0.10 のままとし、二重の用量にはしない**（用量上げは慎重に、という設計ルール）。ショート側は変更しない。土台のそれ以外の仕組み（2 銘柄 × 10 トランシェ、保有 20 営業日、2 営業日ごとリバランス、翌日寄付執行、ショート比率 0.5）は AGN と同一とする。
- **比較対象**: AGN（EXP-114 の A_pn、現行キャッシュで再計算したもの）。忠実性条件として、実行スクリプト内で再計算した AGN が下記の EXP-114 確定値を再現しなければ、その実行は無効とする。

## 判定基準（標準3基準 vs AGN、土台対比）

ハウスフレーム: 予算 ¥2,000,000、期間は前半 2017-01-04..2021-12-30 / 後半 2022-01-04..2026-09-25、コストはベース（片道 0.0003、ショート carry 年 3%）と stress（片道 0.0010、年 5%）、2 銘柄 × 10 トランシェ、保有 20 営業日、2 営業日ごとにリバランス、翌日寄付執行。

AGN の確定値（EXP-114）: FH 利益 +¥1,016,904 / 比率 0.374（DD −22.98%）、SH 利益 +¥4,104,036 / 比率 1.599（DD −16.66%）、フル stress 利益 +¥4,884,260 / 比率 0.472。

1. ベースコスト利益が両半期ともプラス。
2. 年率/DD 比率が両半期とも AGN を上回る。
3. フル期間 stress で利益プラスかつ比率が AGN を上回る。

全て満たせば PROMISING とし、フォワード・ペーパー統合と再演判定（EXP-086 方式の登録条件）に進む。1つでも欠ければ不採用として結果を記録する。基準・構成・指標は結果を見て変更しない。なお判定は AGN 対比のみで行い、A 対比の数値は参考として記録するに留める（A 対比で通っても AGN 対比で落ちれば不採用）。

## リスク・留保

- **多重検定・近傍亜種**: EXP-114 の近傍亜種であり、挑戦者は約66番目以降。本登録の存在理由は「H1 ラインは測定されていなかった」という未測定角度と、増分が記述段階で消滅しなかった点にあり、独立した新しい証拠ではない。EXP-116（OP 合体）が土台対比で落ちた先例があるため、落ちる可能性は十分あると見込む。
- **土台 AGN 自体の留保**: AGN のブックテスト後半通過は比率 +0.015 の薄いマージンで、再演（EXP-115）では DD 浅化が再現せず利益側で条件 (i) を満たした形だった。土台の優位が経路依存である以上、本実験の AGN 対比マージンも薄くなりやすい。
- **捕捉可能性**: 記述効果の約76% は公表後 5 日目までに生じる。翌日寄付執行の簿が捕捉できるのは残りの部分のみ。EXP-114 はこの留保を抱えたまま通過したが、それは本実験の通過を保証しない。
- **被覆の偏り**: NxFNp2Q は FY 行のうち 1,669 件にのみ存在し、H1 旗の判定可能範囲は全 FY の約半分。旗が立たないのは「H1 予想なし」と「減益でない」の混在であり、この非対称は結果文書で定量化する。
- **閾値・用量の固定**: −10% の閾値と −0.10 の用量は EXP-114 と同一に固定し、結果を見て動かさない。≤0.80× の旗が記述上より強いこと（−3.73%）を見て閾値を切り替える案、H1 OP ラインの追加案は、いずれも結果後の調整になるため登録しない。
- **補完手続き**: NxFNp2Q の補完（同一 (code, CurFYEn) グループ内の最新非欠測行）は EXP-114 の NxFNp 補完と同一手続きを適用する。補完が旗に影響する件数は結果文書で定量化する。
