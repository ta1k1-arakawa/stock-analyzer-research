# EXP-089 計画：EXP-087B・087C・088 のフォワード統合（ペーパー AF15・A625・AB）

ブックテストで通過した3変種をペーパーとして追加し、再演で検証する
（EXP-081/082/086 と同じ手順）。ライブ A・実弾 V は不変。

- **AF15**: EXP-087B（habit 割引 ×1.5）。forward の fc 係数を
  1 + 1.5×(係数−1) に変換して適用。ショートは AF15_s。
- **A625**: EXP-087C（ショート比率 0.625）。スコアは A と同一。
- **AB**: EXP-088（大量保有の買い増し追随、全 filers、+0.10）。
  forward/broad_events.csv にアーカイブから 516 件を種入れし、
  update_broad_events が日次で追記する。ショートは A に従う。
