# EXP-038 事前登録:円ショック・ゲート(A のロングを半分にする)

状態: 計画(未実行)

## 背景・仮説

文献探索第2弾の第7案(DD 対策パッケージ)のうち、為替ゲートだけを切り出して試す。日本のロングショートを殺すドローダウンは円を介したデレバレッジであり、株価のトレンドではなく資金通貨で捉えるべきだ、というのが原案の主張(BIS 2024:2024年8月5日に TOPIX −12%、USD/JPY は約3週間で 162→142)。
DD 診断でも、A の暴落型局面ではロングが市場以上に落ちることが確認されている。プットスプレッドの重ね掛けは、原案でも「二重払い」の懸念があり、データ整備も重いため本実験には含めない(ゲートに何かあれば別途検討する)。

## 設計(すべてこの事前登録で固定する)

- データ:USD/JPY 日次 = FRED DEXJPUS(無料、キー不要)。東証の取引日へ前方埋めし、先行バイアスを避けるため **1取引日遅らせて**使う(FRED の値は米国正午レートで、日本時間では翌日未明に確定するため)
- ゲート条件:USD/JPY の **20 取引日変化率が −5% 以下**(=円が急騰)になった日の翌日から **10 取引日**、ゲート ON
- ゲート ON の間:A の建玉を **ロング 0.5 / ショート 0.5**(通常時 1.0 / 0.5)にする。ネットは +0.5 → 0 になる。銘柄選択・スコアは A のまま
- 閾値 −5% と窓 10 日はここで固定し、結果を見て調整しない。エンジンは日次で比率を変えられる simulate の派生版を使い、ゲート常時 OFF の設定で A を正確に再現することを実行時に検証する
- 比較対象は A(S も併記)。期間・費用は従来どおり

## 判定基準(A に対する通常の3基準)

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

## リスク・注意(結果を見る前に)

- 較正の根拠は実質 2024年8月(と部分的に 2020年3月)の 1〜2 イベントしかない。通常の円高(介入など)で誤発動すれば、EXP-019(トレンドフィルター)と同じく回復局面の利益を削る
- ゲートが発動する局面でも、A のファクター冬型(2021年秋・2026年春)の DD は防げない
- FRED の休日・欠測は前方埋めで処理する
