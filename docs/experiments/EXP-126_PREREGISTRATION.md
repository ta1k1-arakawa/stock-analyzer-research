## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で当該側の実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: EXP-125 と完全に同一（ギャップ = 寄付価格 ÷ 前営業日終値 − 1、ロング側 ≤ −5% / ショート側 ≥ +5%、同一銘柄・同一日は最大1イベント、分割疑い日と前営業日終値が得られない日は対象外）。
- **エントリー**: **寄付価格**で、ロング側は買い、ショート側は売る（EXP-125 と同一）。
- **エグジット**: **翌営業日の引け**で全量を反対売買する。翌営業日が暦日で10日を超える場合は対象外（記述と同一）。引け価格が得られない（売買停止等）場合は、引け価格が得られる最初の後続営業日に繰り延べ、その旨を台帳に記録する。

- **ベンチマーク**: 各イベントについて、同窓（エントリー日の寄付→翌営業日引け）の TOPIX 変化率を記録し、超過リターン = イベント損益率 − 同窓 TOPIX 変化率 × 方向符号（ロングは差し引き、ショートは 損益率 + TOPIX 変化率）とする。

## サイジングと台帳（イベント台帳型、EXP-120 / EXP-124 / EXP-125 と同型）

- **枠**: フォワード共通の予算 ¥400,000 を記録上の枠とする。ペーパーであり実資金は動かさない。
- **1 イベントの金額（想定元本方式）**: 1 イベント = **¥20,000 の想定元本**、株数は 20,000 / 寄付価格で**端数株を許容**する。

## 実現可能性の記録（ショート側のみ必須、EXP-124 / EXP-125 と同型）

ショート側について、各イベントに次を記録する:

1. **貸借銘柄か否か**（イベント日時点で制度信用で空売り可能か）。
2. **空売り価格規制の該当**（イベント日および保有をまたぐ翌営業日にトリガー抵触があったか）。
3. **寄付オークションの約定有無**。
4. **逆日歩の発生有無と金額**（日をまたぐ保有のため本実験では現実の論点。発生した場合は1株あたり金額を追記で記録）。
5. **貸株料の扱い**（標準料率ベースの計算値を実績記録として残し、料率の出典と適用日を明記）。

**実行不能の定義と集計（ショート側）**: 1 で貸借銘柄でない、または 3 で寄付に約定が無いイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。ロング側は寄付オークションの約定有無を観測項目として記録する。

## 判定（フォワード専用、固定。側ごとに独立）

- **中間集計**: 各側について、最初の **50 件の完了イベント**が揃った時点で、勝率、平均損益率、中央値、TOPIX 超過リターンの平均を集計して記録する（ショート側は実行不能率も併記）。中間集計では採否の結論は出さない。
- **最終判定**: 開始から **12 か月時点**で、その時点で完了している全イベントについて同じ集計を行い、側ごとに結論を出す。単元額（寄付価格 × 100 株）の分布と中央値も必ず併記する。
- **結論の規則（固定）**: 最終判定で、当該側の判定主軸の集計について次の全てを満たす場合に「当該側の主張を前方データが支持した」とする。
  1. 平均損益率がプラス。
  2. TOPIX 超過リターンの平均がプラス。
  3. 中央値が −0.50% 以上。
  4. ショート側のみ: 実行不能率が **50% 以下**。

  1・2 の片方のみプラスは「部分的に支持」、1・2 ともマイナスは「支持しない」。3 または 4 を満たさない場合は、1・2 がプラスでも「支持しない（理由: 尾部依存 / 実行不能率）」とする。片側の結論は他方に影響しない。**EXP-125 の結論とも独立**であり、一方が支持され他方が支持されなくても矛盾ではない（保有期間の違いそのものが判定対象）。閾値・集計対象は結果を見て変更しない。
