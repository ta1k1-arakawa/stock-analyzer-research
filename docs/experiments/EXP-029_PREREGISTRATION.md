# EXP-029 事前登録：政策保有株の縮減ティルト（EDINET 有価証券報告書）

状態: 計画（未実行）。データ項目の存在はプローブで確認済み

## 背景・仮説

文献探索（2026-10-31）の第6案。東証のコーポレートガバナンス改革で政策保有株式の縮減が進み、縮減を進める企業は資本効率の改善とガバナンス評価の向上が見込まれる。有価証券報告書の貸借対照表から「投資有価証券 ÷ 純資産」の前年比低下を測り、縮減が速い銘柄を優遇する。新しいデータ源（EDINET）・新しい情報（保有資産の構成変化）であり、価格・予想修正・信用取引のいずれとも別系統である。

## データとシグナル（すべてこの事前登録で固定する）

- 対象書類: EDINET の有価証券報告書（docTypeCode 120、訂正 130 があれば優先）。銘柄は EXP-002 の 306 銘柄。日次リストは EXP-012 で取得済みのキャッシュを再利用する
- 抽出項目: 投資有価証券（InvestmentSecurities）と純資産（NetAssets）、いずれも CurrentYearInstant。連結（コンテキストが正確に CurrentYearInstant）を優先し、無ければ単体（_NonConsolidatedMember）を用い、どちらを使ったか記録する
- 比率 ratio = 投資有価証券 / 純資産（純資産 ≤ 0 の場合は欠損）
- シグナル: 時点 d で利用可能な直近2期の比率から reduction = ratio（前年） − ratio（当年）。正 = 縮減が進んでいる
- 時点規律: 利用可能になるのは EDINET の提出日時の翌営業日以降ではなく、**提出日を含む最初の営業日**から（EXP-012 の規約に合わせる）。次の報告書までフォワードフィル
- レッグ: A の有効集合の中で reduction を日次パーセントランク化。2期分が揃わない銘柄は中立 0.5（EXP-012 の規約）
- **A_cross = (comp_r + mom_r + cross_r) / 3**。比較対象は A（S も併記）
- **被覆ゲート**: 評価期間を通じ、A の有効銘柄のうちシグナルが非欠損の割合の中央値が 50% 未満なら、バックテストを行わず報告して止まる（EXP-012 の前例）

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- 投資有価証券は政策保有の代理変数であり、運用目的の有価証券も含む。金融業では事業そのものであるため比率の意味が異なるが、除外はしない（宣言）
- シグナルは年1回しか更新されず、変化は緩やか。効果は小さい可能性がある
- 提出日時ベースのため EXP-012 と同じく短信より情報が遅い。年次の遅さは避けられない
- この案は文献探索で根拠が最も弱い部類だった（日本での公表バックテストなし）。検証自体が目的である
