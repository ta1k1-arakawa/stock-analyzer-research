# EXP-099 計画：EXP-098B（AB 段階化・強）をフォワードのペーパーで検証する

EXP-089/091/096 と同じ手順。EXP-098 で適応基準（後半のみ）を通過した
段階化ボーナス（弱い買い増し +0.10、強い買い増し +0.20）を、次の
ステップからペーパー **ABG** として追加し、登録条件つきの再演で
判定する。ユーザーが 2026-11-07 に承認済み。

## ABG の定義

- 対象イベントは AB と同じ（EXP-088：type 1 の新規提出、または
  type 2 で保有比率の増加が 1pt 以上、全 filer）。提出日の翌日から
  120 暦日有効。
- 段階化は EXP-098B の分類どおり：**strong** = type 2 の増加が
  3pt 以上、または type 1 の保有比率が 10% 以上。それ以外は weak。
  同一銘柄日に strong と weak が重なれば strong が優先（ブック
  テストの意味論と同じ）。
- ロング側ボーナス：strong +0.20 / weak +0.10（AB は一律 +0.10）。
  ショート側は AB と同じく A に従う。

## フォワードのフィード変更

forward/broad_events.csv に strength マーカー（3 列目 "strong"
0/1）を追加する。後方互換：broad_flags（AB 用）は従来どおり
date/code のみで動作し、挙動は変わらない。update_broad_events は
取得時点で EXP-098 の規則により strong を分類して記録する。
既存のシード 516 件の strength は EXP-098 のアーカイブ分類
（ブック 535 件中 strong 142 件、(date, code) で名寄せ後 516 件中
135 件）から付けた。シード後に日次フィードで追加された 2 件
（2026-11-06 分）は API で再分類し、どちらも weak だった。

## 再演と登録条件

EXP-055 型ハーネスで 2022-01-04〜2026-09-25、予算 ¥400,000、
ポートフォリオ S/A/AB/ABG を再演する。登録条件は従来どおり、
ABG について (i) 再演の利益が再演 A 以上、または (ii) DD が再演 A
より浅く年次/DD が再演 A を上回る、のどちらかを満たせば
「観測を続ける根拠あり」。両方とも満たさなければ「根拠なし」と
記録する（ペーパーは撤去しない）。

check 1（再演 A がスケールしたバックテスト A の ±5% 以内）は、
フォワードが系統的に約 +8.1% 熱く出る既知のパターンで不通過に
なる見込みであり、判定の物差しは相対条件 (i)/(ii) とする。
ABG と AB の比較は登録条件ではなく観測として記録する（ABG が
元の AB を上回らなければ、段階化は AV の AVG と同じく上積みに
なっていないことになる）。

ABG は AB の改良形であり独立な発見ではない。判定は後半のみの
適応基準を通過した段階であり、マージンは薄い。裁定はフォワード
の実績に委ねる。ライブ A と実弾 V は変更しない。
