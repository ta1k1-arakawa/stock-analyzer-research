# EXP-033 事前登録:TDnet 悪材料イベントは 306 銘柄で捕捉できるか(記述的イベントスタディ)

状態: 計画(未実行)。**本実験に合否基準はない。** イベント数が少なく、記述統計として実施する。

## 背景

文献探索第2弾の第2案。株主優待廃止(大和総研 2023:翌日 -5〜6pt、10日目 CAR ≈ -6%)と希薄化を伴う資金調達(Karpoff et al.:3日 CAR -5.89%)は全市場サンプルの話であり、当研究の 306 銘柄で件数と捕捉可能なドリフトが残るかは未検証だった。探索レポート自身の死活条件:「公表翌日(open)から +10 日までの捕捉可能ドリフトが 1% 未満なら、このスリーブは成立しない」。

## データ(取得済み・無料)

- TDnet 開示タイトルを無料ミラー API(やのしん webapi)から日次リストで取得:2016-10-01〜2026-09-30 の全 3,652 日、漏れなし(2022-11-21〜23 は初回失敗後に再取得で回復)。306 銘柄分 33,939 件
- 価格は EXP-002 キャッシュ(日次 OHLC)

## イベント分類(タイトル規則をここで固定)

- **Y(優待廃止)**:タイトルに「優待」かつ「廃止」を含む = **14 件**
- **ISS(希薄化発行の発表)**:「発行」を含み、対象が新株式/新株予約権付社債/転換社債、かつ第三者割当または公募。ただし 払込完了・訂正・子会社・取得・繰上償還・権利発生・行使価額の修正・信託・変更 を含むものは除外 = **75 件**(前半 38 / 後半 37、44 銘柄)。タイトルに「提携」を含むもの(資本業務提携に伴う割当で、悪材料とは限らない)を ISS-A、含まないものを ISS-P として分けて集計する

## 測定(固定)

- エントリー:開示日の**翌取引日の寄り付き**(取引可能な形に限定)。公表当日の終値基準では測らない
- 保有:+5 / +10 / +20 取引日の終値まで。超過リターンは同期間の TOPIX 対比
- クラス別・期間(前半/後半)別に、平均・中央値・下落率(ショートが当たる割合)を報告する
- 解釈の事前宣言:いずれのクラスも +10 日の平均超過が -1% に届かなければ(ショートで 1% 取れなければ)、306 銘柄ユニバースではスリーブ不成立と結論する。届くクラスがあれば、別途スリーブ実験として事前登録し直す

## リスク・注意

- 件数が少なく(特に Y=14)、統計的な結論ではなく「この規模で測れるか」の確認である
- タイトル分類はキーワードのみで、希薄化率や調達額の大きさは見ていない
- ミラー API は非公式の無料ミラーであり、網羅性は TDnet 公式と同一と仮定する(全 3,652 日のリスト取得は完了)
