# EXP-085 事前登録：ファクター冬専用の部分セクター中立化（第10弾 候補5・記述ゲート）

根拠（内部証拠）：DD 診断の2件のファクター冬（2021年秋、2026年春）は
市場無風でロングだけが沈んだ。EXP-022 の常時セクター中立は前半に効いて
後半に時代反転した。本候補は「A の業種エクスポージャーが極端なときだけ
半分戻す」部分中立化だが、022 の焼き直しリスクが最も高いため、
まず記述ゲートだけで判定し、通らなければブックテストに進まない。

## 記述ゲート（キルルール）

以下を両方満たさなければキル：
(a) 発動日割合（A 上位20銘柄の業種ウェイトと TOPIX 業種ウェイトの
    乖離が過去 80%ile を超える業種が存在する日）が 10〜40% の範囲。
(b) ファクター冬2エピソード（2021-09〜11、2026-02〜05）における
    A ロング簿の業種乖離が、平常時より大きい。

## 通った場合の定義（参考）

発動業種についてのみ、その業種内での再ランク付けにより業種ウェイトの
乖離を半分に縮める。それ以外は A のまま。判定は標準3基準（対 A）。
