# EXP-100 事前登録：新しい芽 4 本（短レバーの用量マップ ×2、異ファミリーの合成 ×1、大量保有の減少側 ×1）

登録日: 2026-11-07（実行前に登録し、結果を見る前に push する）
背景: ユーザーの「どんどん他にも芽を作ってください」（2026-11-07）を受けた
バッチ。第10弾の設計原則に従う：(1) 遅い非価格シグナルへのソフトな傾け、
(2) フォワード再演で相対優位が再現した脚の合成、(3) 利益主張より DD 主張を優先。

共通の枠: EXP-002 キャッシュ、予算 ¥2,000,000、前半 2017-01-04〜2021-12-30、
後半 2022-01-04〜2026-09-25。S と A はスクリプト内で再計算し、公表値
（A: 前半 +¥1,001,487・比率 0.348、後半 +¥4,160,686・比率 1.605、
全期間 stress 比率 0.421）を正確に再現しなければ実行全体を無効とする。

標準 3 基準（対 A）: (1) base 損益が両半分とも > 0、(2) 年次/DD 比率が
両半分とも A を上回る、(3) 全期間 stress 損益 > 0 かつ比率が A を上回る。
適応基準（後半のみ、大量保有アーカイブが 2021-07 開始のため。EXP-052/088/098
と同じ枠）: (1) 後半 base 損益 > 0、(2) 後半比率が比較対象を上回る、
(3) 後半 stress 損益 > 0 かつ比率が比較対象を上回る。**適応基準の通過は
標準基準の通過より弱い判定であり、結果文書でも混同しない。**

## 100A — AVF15625（AVF15 × ショート 0.625）

構成: EXP-090B の AVF15 スコア（A の予想ROE成分に予想の癖ハイアカット
×1.5 を適用し、ロングに任意開示ボーナス +0.10、喪失回避銘柄はロング除外、
ショートは AF15 スコア）そのままに、ショート比率だけを 0.5 → 0.625 に変える。
根拠: 同じ短レバーを AF15 にかけた AF15625 は再演で最良の比率 2.078 を出し、
AVF15 は再演で最も浅い DD（−15.33%）だった。2 つの再現済み DD 脚の合成。
判定: 標準 3 基準（対 A）。参考として AVF15（0.5）も同一実行で出す。

## 100B — ABGF15（ABG 段階化 × AF15）

構成: AF15 スコア（100A の fc スコア。ロングは喪失回避除外つき）を土台に、
EXP-098B の段階化ボーナスをロングへ加える（strong +0.20 / weak +0.10、
strong 優先、分類は EXP-098 と同一）。ショートは AF15 スコア。
根拠: ファイリング系（大量保有）と予想の信用系という別ファミリーの
非価格シグナルで、それぞれ単独では通過している。
比較対象: 土台である AF15（脚の増分価値を見るため。対 A の数値も併記する）。
判定: 適応 3 基準（対 AF15）。
**最大のリスク（事前に明記）**: EXP-067 の教訓 — 利益脚の合成は後半 DD を
深くし比率で落ちる型がこのプログラムの天井である。2 脚とも利益脚寄りの
ため、この失敗形が最有力の代替仮説である。

## 100C — AV625（AV × ショート 0.625）

構成: EXP-054 の AV スコア（A + 任意開示の厚み増加ボーナス +0.10、ロング
のみ、ショートは A）にショート比率 0.625 をかける。
根拠: AV は相対優位がフォワード再演で完全再現した唯一のシグナル
（EXP-055）。0.75 版（AV75）は再演条件 (ii) を通過し、0.625 は
EXP-087C で 0.75 より利益の目減りが半分だった。用量マップの欠けた点。
判定: 標準 3 基準（対 A）。参考として AV（0.5）も同一実行で出す。

## 100D — 大量保有の「減少」ペナルティ

未検証の鏡像側：大量保有者が減らす動きがその後の劣後を先行するか。
イベント: type-2 報告で TotalShsRatio − TotalShsRatioLast ≤ −0.01
（1pt 以上の減少）。type-1 の消滅はアーカイブの構造上同定できないため
対象外と明記する。
**記述ゲート（3 条件すべて満たさなければブックテストせずキル）**:
(a) イベント ≥ 100 件、かつ後半のフラグ銘柄数/日の中央値 ≥ 5
（フラグ = SubDate の翌営業日から 120 暦日）、
(b) 後半のイベントについて、フラグ銘柄の 20 営業日先行リターン
（ユニバース平均との差）の平均が負。
ゲート通過時のみブックテスト 1 形: ロングに −0.10（イベント後 120 日）、
ショートは A のまま。判定: 適応 3 基準（対 A）。

試す資格」であって採用ではない（EXP-046/052/054/080 の前例どおり、
判定は再演とフォワード実績が持つ）。

DD 機械レバーとして再演で再現した実績があり、価格シグナルとは区別する。
