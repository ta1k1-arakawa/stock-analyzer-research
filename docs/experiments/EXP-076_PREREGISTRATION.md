# EXP-076 事前登録: 権利落ち後ペナルティの回避形(EXP-070 の未登録形)

## 既知事実の宣言(重要)

本実験は後付けである。EXP-070 の記述的段階で、高利回り銘柄の落ち後20営業日の
TOPIX 超過リターンが前半 −1.296% / 後半 −1.836% であることを**既に測定済み**
であり、その事実を知った上で回避形を登録する。したがって本バックテストは
発見の証拠としては数えず、通過してもフォワード・ペーパーでの仲裁を必須とする
(EXP-046/052 の前例と同じ扱い)。EXP-070 で登録したボーナス形の判定は変えない。

## 登録形(単一・固定)

- 落ち日は EXP-070 と同じ導出(基準日=期末・第2四半期末、精算整合の落ち日)。
- イベントごとに、落ち前11営業日の終値に対する直近配当(DivAnn / 中間は Div2Q
  系列の直近値)の利回りを計算し、同一年のイベント内の中央値以上を「高利回り」
  とする(EXP-070 の測定母集団と同一定義)。
- A_exa のロング・スコア: 高利回りイベントの落ち日から20営業日間(落ち日を含む)
  は当該銘柄をロング側から除外(新規組み入れ対象外)。ショート側は A のまま。
  既存保有の強制売却はしない(トランシェの自然な満期に任せる)。
- 実装は EXP-013 の simulate2(ロング/ショート別スコア)を使う。

## 判定

標準3基準 vs A:(1) 基本コストで両期間とも黒字、(2) 年率÷DD 比率が両期間で
A 超え、(3) 全期間ストレスで黒字かつ比率が A 超え。通過しても上記の宣言通り
フォワード・ペーパー仲裁なしにライブ採用はしない。
