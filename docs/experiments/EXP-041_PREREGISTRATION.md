# EXP-041 事前登録:決算集中日 × サプライズの注意散漫(記述的イベントスタディ)

状態: 計画(未実行)。EXP-033/036 と同じく合否基準のない記述的研究とし、本への組み込みは下記のキルルールを通過した場合のみ別途事前登録する。

## 背景・仮説

文献探索第3弾の第2案。決算発表が集中する日は投資家の注意が分散し、個別の決算サプライズへの初期反応が鈍って、その後の数日〜10日でドリフトが続く(森脇 2016、日本 2004–14)。ただし同論文の留保は重い:経営者予想ベースのサプライズでは交互作用が有意でなく、純利益ベースでも有意でなく、外れ値除外でドリフトが消える。本実験は「安い反証テスト」であり、外挿案の真偽を小さいコストで確かめることが目的である。

## 測定方法(この事前登録で固定する)

- イベント:EXP-018 の予想追跡機械を流用し、FY・2Q の実績純利益が直前の会社予想(FNP/FNP2Q)を **+10% 以上上振れ(pos)/ −10% 以上下振れ(neg)** した開示を両方向で収集する(EXP-018 は pos のみだった)
- 集中日:その開示日に 306 銘柄中で決算開示(FY/1Q/2Q/3Q)を行った銘柄数を数え、全期間の開示日分布の **上位 3 分の 1 を busy**、それ以外を non-busy とする
- 測定:開示日の翌取引日寄り付きで入り、TOPIX 超過リターンを +5/+10/+20 営業日で測る(EXP-033/036 と同じ測り方)

## キルルール(+10 日で判定)

符号付きドリフト = pos 群の平均超過リターン、neg 群については −(平均超過リターン)(下振れが下方にドリフトすれば正)。
**交互作用 = (busy の符号付きドリフト − non-busy の符号付きドリフト)** とし、pos/neg の平均を主統計量とする。

- 交互作用が **+0.5% 未満** なら、この方向は閉じる(本テストには進まない)
- +0.5% 以上なら、本への組み込み案を別途事前登録して検討する

## リスク・注意(結果を見る前に)

- 当方のサプライズは会社予想ベースであり、森脇で有意だったのは実績ベース(コンセンサス系)寄りの定義である。定義の外挿であることを明記する
- busy 判定は全期間分布で固定する(将来情報ではなく、分類規則の固定である)
- 件数が薄いセル(特に neg × busy)では平均が数件に支配されうる。中央値と件数を併記する
