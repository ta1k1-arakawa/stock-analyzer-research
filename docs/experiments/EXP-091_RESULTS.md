# EXP-091 結果：EXP-090 通過 3 本のフォワード再演（2022-01-04〜2026-09-25）

EXP-090 で全基準を通過した 3 本（AF125・AF15625・AVF15）の再演検証。
EXP-089 と同じ手順・同じ登録条件。ライブ A・実弾 V は不変。検証手順は
EXP-081/082/086/089 と同じ。

- **AF125** = 予想の癖の割引 ×1.25（EXP-090C、全期間利益 +¥8,312,155 は
  全挑戦者で最高）
- **AF15625** = AF ×1.5 ＋ ショート比率 0.625（EXP-090A）
- **AVF15** = AF ×1.5 のロングに AV ボーナス +0.10（EXP-090B、
  後半比率 2.151 は全挑戦者で最高）

登録条件（EXP-086/089 と同じ物差し）：再演で (i) 利益が再演 A 以上、
または (ii) DD が再演 A より浅く年次/DD が再演 A を上回る、のどちらかを
満たせば継続の根拠あり。両方とも満たさなければ「継続の根拠なし」と
記録する（削除はしない）。

1.981）。同じ実行で回した再演の再現性が確認できた。

## 判定

- **AF125・AF15625・AVF15 は 3 本とも両条件を満たす**。利益は A を
  +¥142,498〜+¥193,664（+16〜+22%）上回り、DD は 2.3〜3.9pt 浅く、
  年率/DD は 1.850〜2.078 と A の 1.476 を大きく上回る。3 本とも利益と
  DD の両方で A を上回った。EXP-090 のバックテストの優位はフォワード
  実行力学の下でも再現した。
- ただし 3 本とも同じ AF レバーの派生であり、独立な発見ではない。
  バックテストで最高だった AF125（全期間 +¥8,312,155）は再演では
  AF15625（+¥1,092,945）と AVF15（+¥1,042,672）に利益で及ばず、
  再演での順位はバックテストと一致しない。AF15625 が再演では
  年率/DD 2.078 で最も高く、DD も AVF15 に次いで浅い。
- AF15（EXP-089）も両条件を満たし、照合どおり再現した。
