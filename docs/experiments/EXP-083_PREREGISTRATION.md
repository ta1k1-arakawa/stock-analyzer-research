# EXP-083 事前登録：綱引き tilt × ショート 0.75（第10弾 候補2、前半対策）

根拠（内部証拠）：EXP-037（綱引き tilt）は前半比率 0.516 と全期間比率
0.836（全挑戦者最高）を出しながら、後半 DD −19.42% のみで落ちた。
EXP-035 のショート 0.75 は後半 DD を浅くする再現済みのレバーである。
037 の失敗は「利益」ではなく「後半 DD」であり、そこだけを独立した
DD レバーで相殺できるかという一点の検証である。037 単独の再掲ではない。

## 定義

EXP-037 のスコア（複合＋修正モメンタム＋綱引きランクの平均、ロング側
tilt、ショートは A）をそのまま使い、 simulate の short_frac を 0.5 から
0.75 に変える。変更点はこの1つのみ。

## キルルール（先行）

後半だけを先に計算し、スタックの後半最大 DD が A の −16.76% より
深ければ、その時点でキルし全判定に進まない。

## 判定基準（標準3基準、対 A）

1. 前半・後半とも base コストで利益がプラス
2. 前半・後半とも 年率/DD 比率が A を上回る
3. 全期間 stress で利益がプラス、かつ比率が A を上回る

EXP-067（失敗した脚のスタックで後半 DD −25.6%）への反証試験でもある。
067 との違いは、重ねる片方が利益の脚ではなく再現済みの DD レバーである点。
