# EXP-026 事前登録：信用買い残の混雑銘柄をロングから除外

状態: 計画（未実行）

## 背景・仮説

文献探索（2026-10-31）の第3案。これまでの失敗はすべて「後半の単一の深い DD エピソード」に帰着した。信用買い残の偏った銘柄は、急落局面で追証の投げが投げを呼び、下落を増幅させる（2024年8月急落の直前、信用買い残は18年ぶりの高水準だった）。ロング側から混雑銘柄を外せば、平時の利益を大きく損なわずに暴落局面の傷を浅くできる可能性がある。

## データ

- J-Quants /v2/markets/margin-interest（銘柄別・週次）を 306 銘柄ぶん取得する（2016-10-31〜2026-09-30、Standard で取得可能であることを確認済み。トヨタで全期間 506 週ぶん取得できた）
- 混雑度 = LongVol（信用買い残株数）/ 発行済株数。発行済株数はパネルの時価総額 / 終値で近似する
- 時点規約: 週次残高（金曜時点）は翌週に公表されるため、**参照日 + 4暦日以降の最初の営業日**から利用可能とし、前方補完する（実績の PubDate は翌営業日〜数日であり、この遅延は保守側）

## 方法

- crowding_rank = その日の A の有効集合内での混雑度の百分位ランク
- **A_mgn**: crowding_rank ≥ 0.90（上位1割）の銘柄のロングスコアを NaN にする。空売り側は A のまま不変（EXP-013 の simulate2）
- バリアントは1本のみ。しきい値 0.90 はこの事前登録で固定する
- 比較対象は A（S も併記）。期間・費用は従来通り

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- 根拠は実務・エピソードベースであり、学術的なバックテスト検証は見つかっていない（文献探索でも弱い証拠と明示）。したがって本実験自体が検証である
- 週次データ＋公表遅延のため、急落の初動には間に合わないことがある
- 混雑度は流動性・サイズと相関しうるため、効果が「小型株回避」と区別できない可能性
- 信用買い残の多い銘柄は同時に人気・モメンタムの強い銘柄でもあり、平時の利益を削る可能性
