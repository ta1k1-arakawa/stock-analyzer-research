# EXP-082 事前登録：再現済み DD レバーの合成（A75F）と再現済み信号との合成（AV75）

第10弾（自己マイニング、research_notes/round10-self-mining）の候補1と候補3。
根拠は文献ではなく自分たちの再現検証5件の横断分析：再現フィルターは
「利益の優位」を罰するが「DD の改善」は両方とも再現した（A75 の DD 浅化、
AF の DD −19.20%→−17.68%・比率改善）。本実験は実験型ではなく運用型で、
フォワードにペーパーを追加し、再演（2022-01-04〜2026-09-25）で判定する。

## A75F = AF のスコア × ショート比率 0.75

- 定義：exp004_forward の AF（EXP-080/081 の予想 habit 割引）と同一スコア、
  SHORT_FRAC_BY["A75F"] = 0.75。ロングは AF、ショートは AF_s に従う。
- 登録条件（再演、対 再演 A）：(i) 最大 DD が再演 A・A75・AF のいずれより
  も浅い、(ii) 利益が再演 A の 90% 以上、(iii) 年率/DD が再演 A を上回る。
- **キルルール：再演 DD が AF 単独（−17.68%）以下に浅くならなければ
  組み合わせは無意味としてキルし、ペーパー A75F は撤去する。**

## AV75 = AV のスコア × ショート比率 0.75

- 定義：forward の rank["AV"]（A + 任意開示ボーナス 0.10）と同一スコア、
  SHORT_FRAC_BY["AV75"] = 0.75。ショートは AV と同じく A に従う。
- 登録条件（再演）：(i) AV75/A 利益比が AV 単独の再演比 1.0953 を下回ら
  ない、(ii) DD が再演 A より浅い。
- **キルルール：再演の AV75/A 利益比が 1.00 未満ならキルし、ペーパー
  AV75 は撤去する。**（1.00〜1.0953 は「死なないが条件未達」として記録）

## 手順

forward_live に両ペーパーを追加（バックアップ取得、ライブ A・V は不変）。
再演は EXP-055 ハーネスで S/A/A75/AF/A75F/AV/AV75 を一括実行する。
再演の A は既知の +8.1% ホットパターンを含むため、判定は全て再演内の
相対比較で行う。
