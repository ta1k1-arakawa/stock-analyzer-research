## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: 取引日 t について、当日の最初の5分（9:00–9:05）の出来高 ÷ 当日出来高総量 = share_first5 が **≤ 0.02**、かつ 当日リターン（引け ÷ 前日引け − 1）が **≥ +0.03** を満たす銘柄・日をイベントとする。同一銘柄・同一日は最大1イベント。分割疑い日、出来高ゼロの日、share_first5 が得られない日は対象外。
- **エントリー**: **当日の引けで売る（ショート）**。前方実装では記述と同一の引け価格をエントリー価格として台帳に記録する。share_first5 の確定には当日の分足が必要であり、前方実装は引け後のスナップショット取得（EXP-152 と同型の方式）で足りる（場中のライブフィードは不要）。
- **エグジット**: **翌営業日の引け**で全量を買い戻す。翌営業日に引け価格が得られない（売買停止等）場合は、引け価格が得られる最初の後続営業日に繰り延べ、その旨と逆日歩の実績を台帳に記録する。エグジットの変更はしない。
- **価格**: 損益率は未調整価格どうしの比率とする。保有期間中に株式分割・併合の効力が発生したイベントは、調整済み価格ベースの比率を正として併記する。
- **ベンチマーク**: 各イベントについて、同窓（当日引け→翌営業日引け）の TOPIX 変化率を記録し、超過リターン = イベント損益率 + 同窓 TOPIX 変化率（ショートのため）とする。

## 実現可能性の記録（必須、EXP-124 / EXP-151 と同型）

2. **空売り価格規制の該当**（イベント日にトリガー抵触があったか。日足安値プロキシで記録する）。
3. **当日に出来高があること**（引け価格が成立し share_first5 が算出できていることをもって約定成立とし、引け価格が無い日はエントリー自体を行わないことでこの項目を扱う）。
4. **逆日歩の発生有無と金額**（一晩保有のため発生し得る。取得可能な場合は実績を記録し差し引く。取得できない場合は「取得不可（unavailable）」と記録して差し引かない）。
5. **貸株料の扱い**（制度信用の標準料率 1.15%/年（日本証券金融）ベースの計算値 = 想定元本 × 料率 × 保有暦日数 / 365 を実績記録として残し、差し引く。料率の出典と適用日を集計側に明記する）。

**実行不能の定義と集計**: 1 で貸借銘柄でない、または 3 で引け価格が成立していないイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。
