# EXP-094 事前登録：AV ボーナスの段階化 — 増え方で強弱をつける

根拠：EXP-054 の +0.10 一律は通過したが、EXP-087A の一律2倍は
前半を壊した。では一律ではなく「増え方の大きさ」で段階をつければ
どうか。強い増加（dVolA ≥ 3）だけに厚くし、境界（= 2）は薄くする
形は、一律増量とは別の賭けである。

- **094A（段階・標準）**：dVolA = 2 に +0.05、dVolA ≥ 3 に +0.10。
- **094B（段階・強）**：dVolA = 2 に +0.10、dVolA ≥ 3 に +0.20。

dVolA の定義は EXP-054 と同一（任意開示の直近12か月件数 −
その前12か月件数）。ロング側のみ、ショートは A。
判定は各変種とも標準3基準（対 A）。
