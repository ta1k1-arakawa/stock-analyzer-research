## 仮説（第8弾の原文どおり）

日本の市場に特徴的な暴落は、円高スパイク／キャリートレードの巻き戻しであり、TOPIX の下落は輸出企業の収益 repricing を通じて起きる。海外売上比率はその露出を測る、動きの遅いファンダメンタルな特性である。ロングを国内需要銘柄側へ、ショートを輸出企業側へ傾けることで、為替の時系列もゲートも使わずに、円高暴落の局面で効く構造的なヘッジを組み込める。

判定の性格: これは **DD 主張** であり、利益主張ではない。第8弾も「return/DD でのみ判定せよ、直交する利益主張なし」と明記していた。

## 信号定義（凍結）

### 材料

- ユニバース: EXP-002 キャッシュのパネル 306 銘柄。
- 各銘柄・各事業年度について、EDINET の有価証券報告書（docTypeCode 120）から海外売上比率を 1 つ抽出する（抽出計画は後段）。
- 海外売上比率 ovs = 1 −（本邦の外部顧客への売上 ÷ 外部顧客への売上合計）。第8弾の定義どおり。売上高・売上収益・経常収益のいずれの表示でもよい（ゲートの判定基準どおり）。顧客所在地ベース・グループ会社所在地ベースの別は開示値のまま採用し、CSV に記録するが調整はしない。

### 採用する表の優先順位（抽出前に凍結、ゲートの留保 (b) への回答）

1. 地域別情報ブロック（「地域別情報」「地域別に関する情報」等の見出しで提示される、外部顧客への売上の地域別内訳表）が存在すれば、それを採用する。省略注記・ゼロ注記もこのブロックの一部として扱う。
2. 地域別情報ブロックが存在しない場合のみ、セグメント注記内の地域区分（報告セグメント自体が地域別である場合を含む、例: 7599 IDOM）を採用する。
3. どちらも存在しなければ、その銘柄・年度は unusable。

### 打ち切り値・ゼロの扱い（抽出前に凍結、ゲートの留保 (c) への回答）

- numeric: 内訳表から算出した値をそのまま使う。
- censored: 「本邦の外部顧客への売上高が連結売上高の 90% を超えるため省略」等の注記がある場合は、海外比率が区間 [0, 0.10) にあることだけが分かる打ち切り値として、**ovs = 0.05（区間中点）** を割り当てる。独自バケットにはしない（ランク化する信号では中点扱いが順序を最も歪めないため）。
- zero: 「本邦以外の外部顧客への売上高がない」旨の明記がある場合は **ovs = 0.0**。
- unusable: 信号なし（下記の欠損ルールに従う）。

### 時点規律と欠損ルール（抽出前に凍結、ゲートの留保 (b) への回答）

- ある有報の値は、その **提出日（含む）以降** にのみ使える（point-in-time）。日 t のスコアには、提出日 ≤ t の最新の有報の値を使う（年 1 回、提出日に更新。第8弾の「latest annual securities report … lagged to the filing date」どおり）。
- 欠損ルール: **最新の利用可能な値を無期限に繰り越す**（第8弾の定義が「最新の有報」である以上、これが原定義に忠実な形である。2 年等の繰越上限は置かない）。ある年度の有報が unusable でも、過去の利用可能な値がそのまま生き続ける。
- 提出日 ≤ t の利用可能な値が一度も無い銘柄（上場直後、抽出開始前の期間、4689 LINEヤフーのように開示自体が無い銘柄）は、その日の脚ランク leg_r = 中立 0.5（家の標準形）。

### スコア構成

第8弾の原記録は形について 2 案を併記していた（曖昧さとして明示する）: (hard) トップ 40 バンド内で海外比率の低い半分を優先する形、(soft) スコアランクから 0.25 × 海外比率ランクを差し引く形。方向（ロング = 低い側、ショート = 高い側のミラー）は一義である。本登録では、家の検証済みティルト筐体（第10弾の知見: 柔らかいティルト優先、構築変更は 0 勝 11 敗）に統一し、**soft の精神を家の標準形で実装** する:

- leg_r = その日の A 有効集合内での「国内比率 (1 − ovs)」のパーセンタイルランク（ovs が低い銘柄ほど leg_r が高い）。値が無い銘柄は 0.5。
- スコア A_yb = (comp_r + mom_r + leg_r) / 3。ロング・ショートとも標準の simulate（A と同一の仕組み、ショート比率 0.5）。単一スコアのため、leg_r の低い側 = 海外比率の高い銘柄がショート側に沈むことで、第8弾の「ショートはミラー（輸出企業を優先）」も同じ柔らかさで自動的に満たされる。
- 用量についての留保: 第8弾は「露出は縮小傾向にある（営業利益の為替感応度は FY2016 の約 1.0 倍 → 0.6 倍）のでティルトは控えめに」としていた。家の /3 形は脚の重み 1/3 で、過去の全ティルトと同一であり、これを「控えめ」の実装とする。用量違いは本登録では検証しない。
