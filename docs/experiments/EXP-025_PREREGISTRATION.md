# EXP-025 事前登録：配当方針 tilt（増配予想レッグを A に追加）

状態: 計画（未実行）

## 背景

文献探索（2026-10-31）の第1案。東証のガバナンス改革以降、配当方針の格上げ（DOE 導入・累進配当・還元目標引き上げ）開示への株価反応が大きいという実務研究がある（大和総研：方針開示企業の中央値が約1か月で TOPIX 比 +3pp 程度）。ただし方針テキスト自体は TDnet の今後の開示にしかなく、過去データには存在しない。本実験ではその経済的な足跡である「年間配当予想の引き上げ（利益予想の下方修正を伴わないもの）」を代理変数として、A への tilt として検証する。単独のイベントスリーブにはしない（EXP-015/018 の教訓）。

## イベント定義（結果を見る前に予告なく変更しない）

- 年間配当予想は本番と同じ FY 規約（FY 決算短信では NxFDivAnn、それ以外は FDivAnn）で読み、同一銘柄の連続する開示同士を比較する
- イベント: 配当予想が前回比 **+10% 以上**（前回値 > 0）かつ、同じ開示で純利益予想が下方修正されていない（両値が存在し cur < prev の場合のみ除外）
- キャッシュ全体の供給は事前に数えた: イベント 1,097 件
- 配当性向フィールド（FPayoutRatioAnn）は記録の約16%にしか存在せず疎なため、定義に使わない

## スコア

- イベントの利用開始日 u = 開示日以降の最初の営業日。policy_raw(t) = その銘柄の全イベントについて max(0, 1 − (t−u)/60営業日) の最大値（60営業日で線形減衰）
- policy_rank = A の有効集合内での policy_raw の日次百分位ランク
- **A_pay = (comp_r + mom_r + policy_rank) / 3**（A の有効集合上、他は不変）
- バリアントは1本のみ。比較対象は A（S も併記）。期間・費用は従来通り

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- 代理変数は方針開示そのものではない。増配予想には業績連動の通常の増配も混ざる（純利益の下方修正を伴わないことは要求するが、上方修正と同時の増配は残るため、修正モメンタムレッグとの重なりがある）
- 大和総研の更新では効果は 2025 年後半以降に減衰しつつあるとされる。前半/後半の非対称が出る可能性
- イベントのない銘柄は policy_raw = 0 で一斉に最下位ランクに並ぶため、このレッグは実質「イベント銘柄への加点」として働く
