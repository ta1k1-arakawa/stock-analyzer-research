## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: 取引日の **09:30 時点**で、09:30の1分足終値 p0930 と寄付価格について **p0930 / 寄付 − 1 ≥ +0.02** を満たす銘柄・日をイベントとする（EXP-128 と同一）。同一銘柄・同一日は最大1イベント。分割疑い日、p0930 が得られない日は対象外。
- **エントリー**: **09:30の1分足終値（p0930）で売る**。前方実装では09:30直後の実約定価格ではなく、記述と同一の p0930 をエントリー価格として台帳に記録する（実フィードでの観測価格との乖離は観測項目として残してよいが、判定は p0930 ベースで固定する）。

- **価格**: 損益率は未調整価格どうしの比率とする。保有期間中に株式分割・併合の効力が発生したイベントは、調整済み価格ベースの比率を正として併記する。
- **ベンチマーク**: 各イベントについて、同窓（エントリー日の09:30→翌営業日引け）の TOPIX 変化率を記録し、超過リターン = イベント損益率 + 同窓 TOPIX 変化率（ショートのため）とする。同窓 TOPIX が取得できない場合は、寄付→翌営業日引けの TOPIX 変化率で代用し、その旨を記録する。

## 実現可能性の記録（必須、EXP-124 / EXP-125 / EXP-127 / EXP-128 と同型）

各イベントに次を記録する:

1. **貸借銘柄か否か**（イベント日時点で制度信用で空売り可能か）。
2. **空売り価格規制の該当**（イベント日にトリガー抵触があったか。09:30時点の価格での売りは規制の対象になり得るため、該当の有無を必ず残す）。
3. **09:30時点の約定可能性**（当該1分足に出来高があったか）。
4. **逆日歩の発生有無と金額**（日をまたぐ保有のため本実験では現実の論点。発生した場合は1株あたり金額を追記で記録）。
5. **貸株料の扱い**（標準料率ベースの計算値を実績記録として残し、料率の出典と適用日を明記）。

**実行不能の定義と集計**: 1 で貸借銘柄でない、または 3 で当該1分足に出来高が無いイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。
