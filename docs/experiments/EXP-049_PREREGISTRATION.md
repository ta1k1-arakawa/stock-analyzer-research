# EXP-049 事前登録: FS-lite ガード(Piotroski 型の両端差し替え)

第 4 弾スイープ 2 位。ブレンドではなく、確定した売買候補の両端だけを差し替える非対称ガードとして検証する。

## 仮説

A のロングは B/P の高さゆえに財務の弱い銘柄へ寄る。財務健全性スコアの低いロングは地雷になりやすく、逆に健全性の高いショートは回復して踏まれやすい。両端だけを次点に差し替えれば、シグナル本体を薄めずに DD を浅くできる。

## FS8-lite(固定・通期レコードのみ、各 1 点)

1. NP > 0
2. CFO > 0
3. CFO ≥ NP
4. Δ(NP/TA) > 0(TA は期末値で統一)
5. ΔEqAR > 0
6. Δ(OP/Sales) > 0
7. Δ(Sales/TA) > 0
8. 純発行なし: (ShOutFY − TrShFY) の前年比 ≤ 0

- 前年レコードと比較して計算し、当年度の通期短信 DiscDate から次の通期短信まで有効(年次更新)
- Sales / OP が欠落または Sales ≤ 0 の年度は FS を計算しない(金融業等はこの規則で自動的に対象外)。それ以外の項目の欠落は 0 点

## ガード(固定)

EXP-013 の simulate2 を土台に、トランシェの確定候補だけを変更する:

- ロング: 確定候補に FS ≤ 2 があれば、ランキングを下に見て「未保有・未選択・FS ≥ 3」の最初の銘柄に差し替える。該当がなければ元の候補を維持
- ショート: 確定候補に FS ≥ 7 があれば、ランキングを下位側に見て「未保有・未選択・FS ≤ 6」の最初の銘柄に差し替える。該当がなければ維持
- FS はスコアと同じく前営業日(t−1)時点の値を使う。スコア・配分・費用は A と同一

## データの実測(実行前)

- FS の入手可能性: A 有効銘柄の前半 70.5% / 後半 92.2%
- 介入頻度(上位/下位 20 銘柄の代理測定): FS ≤ 2 のロング候補は 1 日平均 前半 0.57 / 後半 0.85 件、FS ≥ 7 のショート候補は 前半 1.23 / 後半 3.11 件

## 判定

A に対する標準 3 基準(両半分黒字/比率が両半分で A 超え/全期間ストレス)。実装の同一性チェックとして、FS が全て NaN の場合は A を正確に再現することを実行時に確認する。

## リスク(登録済み)

- 日本では F スコアとリターンの関係は近年減衰しているという証拠がある(北川 2020)。両端限定で効きが小さい可能性
- 年次信号のため、開示から最大で約 1 年以上古い情報で判定する期間がある
