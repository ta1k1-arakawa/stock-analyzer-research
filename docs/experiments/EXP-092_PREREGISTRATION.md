# EXP-092 事前登録：配当予想の「癖」割引 — 予想の信用を2つ目の道具で測る

根拠（内部証拠）：EXP-080 で効いたのは「その会社の予想は信用できるか」
という測定であり、道具は純利益予想だった。同じ癖が配当予想にも
あるなら、配当を強気に言い続けて裏切る会社は、他の予想も割り引いて
見るべき対象になる。これは EXP-025（配当上方修正 tilt、失敗）の
焼き直しではない：使うのは修正イベントではなく「初期予想と実績の
乖離の習慣」であり、形は EXP-080 と同じである。

## 定義

- FY 決算短信レコードで、翌期の初期配当予想 = NxFDivAnn、
  その期の実績 = 翌年の FY レコードの DivAnn（> 0 の場合のみ）。
- 年次バイアス = (初期予想 − 実績) / 実績、±2 で winsorize。
- habit = 直近3期分の平均（2期以上必要）。
- エピソード窓：FY 短信の開示日から、その配当予想が変更される
  次の開示、または3か月の早い方（EXP-080 と同じ）。
- 窓の間、habit > +0.10 の銘柄にロング側 −0.10 のペナルティ。
  ショート側は不変。

## 記述ゲートと判定

ペナルティ対象の同時点中央値が 5 銘柄未満なら材料不足として記録。
判定は標準3基準（対 A）。
