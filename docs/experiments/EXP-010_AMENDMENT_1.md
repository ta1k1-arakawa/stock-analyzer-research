# EXP-010 補遺1（AMENDMENT_1）：決算モメンタム脚の定義変更と丸め処理の訂正

```text
date=2026-10-28
reason=事前登録のコミット後、実行前にキャッシュの実データ項目とコードベースを確認したため（結果を見る前の変更）
```

## 変更1：決算モメンタム脚の定義

- 変更前：営業利益の前年比成長の加速＋最新の会社予想ガイダンスの方向
- 変更後：np_forecast（会社予想純利益）の上方修正モメンタム。開示日ベースで直近90日の開示について、上方修正を+1／下方修正を-1として合計したネット値を日次でランク化
- 理由：EXP-002 の J-Quants キャッシュ（financial summary）の保持項目は code, disc_date, disc_time, disc_no, doc_type, per_type, fy_end, equity, np_forecast, shares_out であり、営業利益の項目が存在しない。契約なしで使えるデータに合わせた
- ガイダンス方向の要素は、np_forecast の修正方向として残っている（上方修正＝ガイダンス引き上げ）
- 判定基準・期間・コスト・2バリアントの設計に変更はない

## 変更2：100株単位の丸め処理

- 事前登録ではベースライン条件に「100株単位の丸めオン」と書いたが、コードベースを確認したところ EXP-009（および EXP-003〜008）に丸め処理は存在しなかった
- 訂正：EXP-010 でも丸めはオフとし、EXP-009 と同一エンジンで比較する。丸めの影響は、有望と判定された場合のフォローアップ実験で検証する

## 変更なしの確認事項

- 対象期間・ユニバース（約306銘柄）・資金200万円・片道コスト0.03%・空売りコスト年3%（ストレス時は片道0.10%・年5%）は EXP-009 と同一
- 比較対象の S は同一スクリプト内で同一エンジンにより再計算する（EXP-009 文書の数値と完全一致しない場合は結果文書に記録する）
