## 仮説

改定ドリフトの本体は引け後開示にあり、場中開示は即時に織り込まれてドリフトを残さない。A の改定モメンタム脚を引け後開示の改定だけで構成すれば、脚の質が上がる。

## 信号

- バケット定義:開示時刻 DiscTime が引け時刻以上なら「引け後」。引け時刻は 2024-11-05 の取引時間延長を境に切替(それ以前 15:00、以降 15:30)
- 改定イベントと符号は EXP-010 の定義をそのまま使う(連続開示の NP 予想の差分符号)。イベント集合を引け後バケットのみに絞る
- 脚 = EXP-010 と同じ90日窓の符号合計を横断面ランク化(0.5=中立)
- A_disc = (複合ランク + 引け後モメンタムランク) / 2、A の有効集合内。その他の構築は A と同一
