# EXP-089 結果：ペーパー AF15・A625・AB のフォワード再演（2022-01-04〜2026-09-25）

EXP-087B・087C・088 をフォワードに統合した 3 ペーパー（AF15・A625・AB）の
再演検証。ライブ A・実弾 V は不変。検証手順は EXP-081/082/086 と同じ。

- **AF15**: EXP-087B（habit 割引 ×1.5）。forward の fc 係数を
  1 + 1.5×(係数−1) に変換して適用。ショートは AF15_s。
- **A625**: EXP-087C（ショート比率 0.625）。スコアは A と同一。
- **AB**: EXP-088（大量保有の買い増し追随、全 filers、+0.10）。
  forward/broad_events.csv にアーカイブから 516 件を種入れし、
  update_broad_events が日次で追記する。ショートは A に従う。

## 登録条件の判定（各新規ペーパー）

条件：(i) 利益が再演 A 以上、または (ii) DD が再演 A より浅く
年率/DD が A を上回る。

| ペーパー | (i) 利益 ≥ A | (ii) DD 浅い かつ 比率 > A | 判定 |
|---|---|---|---|
| AF15 | 満たす（+¥1,113,567 ≥ +¥899,281） | 満たす（−16.43% < −19.20%、1.981 > 1.476） | **観測を続ける根拠あり** |
| A625 | 満たさず（+¥876,768 < +¥899,281） | 満たさず（比率 1.474 < 1.476） | **観測を続ける根拠なし** |
| AB | 満たさず（+¥881,607 < +¥899,281） | 満たす（−18.76% < −19.20%、1.491 > 1.476） | **観測を続ける根拠あり** |

## 判定

- **AF15 は両条件を満たす**。利益は A を +¥214,286（+24%）上回り、
  DD は 2.8pt 浅く、年率/DD は 1.981 と A の 1.476 を大きく上回る。
  3 ペーパーの中で唯一、利益と DD の両方で A を上回った。
  habit 割引 ×1.5 の強化はフォワード実行力学の下でも再現した。
- **AB は条件 (ii) を満たす**（DD が浅く比率が上回る）が、利益は
  A を −¥17,674 下回る。比率の上回り幅は +0.015 と薄い。
  観測を続ける根拠はあるが、優位は弱い。
- **A625 は両条件を満たさない**。利益は A を −¥22,513 下回り、
  DD は浅いものの比率は 1.474 と A の 1.476 をわずかに下回る。
  「観測を続ける根拠なし」として記録する（撤去はしない）。
