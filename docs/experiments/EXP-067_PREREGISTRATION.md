# EXP-067 事前登録: 強い失敗材料トリオの合成(第6弾 #7)

2026-11-02 登録。結果を見る前に固定する。

## 警告(第6弾レポートの位置付けを引き継ぐ)

EXP-030(株主総利回り水準)・EXP-025(配当性向の格上げ)・EXP-048(予想信頼性)はいずれも「利益系としては本物らしいが単独では基準に届かなかった」材料である。3つの合成は「約50件試した中から良さげなものを拾う」行為であり、**多重検定による過学習リスクは全候補中最大**。そのため本実験は通常より厳しい判定(基準4の追加)を登録し、仮に通過してもフォワードのペーパー検証を必須とする。

## 記述的キルテスト(実施済み・通過)

合成脚ランクの三分位の翌20営業日リターン・スプレッド:前半 +0.451% / 後半 +1.184%(登録基準:両期間 +0.3% 以上)。三分位は両期間とも単調だった。

## 仮説

出所の異なる3材料(還元水準/配当予想の改定/予想の信頼性)の合成により、単独材料の時代依存性が分散で和らぐ。

## 信号(各材料は各 EXP の登録形をそのまま使い、再定義しない)

- 材料1 TSY: EXP-030 の tsy_frame(予想配当利回り+自社株買い利回り)
- 材料2 配当格上げ: EXP-025 の検出イベント+60日減衰 raw スコア
- 材料3 信頼性: EXP-048 の Cred(過去3期の予想バイアスの中央値)。脚ランクは −Cred のランク(楽観バイアスが小さい=信頼できる側を高ランクとする)
- 合成脚 = A の有効集合内での3材料のパーセンタイルランクの平均。欠損材料は中立 0.5(EXP-030 の登録慣行)
- A_trio = (複合ランク + 改定モメンタムランク + 合成脚ランク) / 3、A の有効集合内

## 判定基準(A 対比)

1. 基本コストの利益が両期間ともプラス
2. 年率/DD 比率が両期間とも A を上回る
3. 全期間ストレスの利益がプラス、かつ比率が A を上回る
4. **(追加の厳格化)** 前半・後半の両方で、ストレス条件の比率も A 以上であること

基準を1つでも満たさなければ「有望でない」。基準は結果を見て変更しない。
