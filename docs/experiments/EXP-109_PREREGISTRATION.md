登録日: 2026-11-09（本書を実行前に push し、その時点で確定する）。常駐指示（2026-11-08）に基づき、通過した場合はユーザーの追加承認なしにフォワード・ペーパー統合まで進める。ライブA・実弾Vは変更しない。

## 仮説

初期予想のうちファンダメンタルズで説明できない部分（残差）が大きい会社は、根拠のない楽観的な予想を出しており、その後の株価が相対的に劣後する。残差が負の会社（ファンダメンタルズ対比で保守的な初期予想）は相対的に堅調になる。Kitagawa & Shuto（Journal of Business Finance & Accounting, 2024）は日本市場で初期予想残差とその後の負の異常リターンの関係を報告している。開示された予想の「水準の質」を見る非価格・年次の遅い信号であり、本プログラムで通過してきた信号の型（任意開示の厚み、予想の癖）に近い。

前提となる記述ゲート（2026-11-09、第12弾）は通過済み: EXP-080 の「予想の癖」（初期予想バイアスの直近3年平均、±2 で winsorize、2年以上必要）との相関を、重複する企業-年度エピソード 2,129 件（287 銘柄、開示年 2018–2026）で実測し、**Pearson +0.038 / Spearman −0.001**（前半 +0.044、後半 +0.034）とほぼ無相関だった。バー（0.3）に対して桁違いに低く、閉鎖済みの癖ファミリーの焼き直しではない。癖が「その会社の過去の平均的な楽観度」という企業特性であるのに対し、残差は「今年の初期予想のうちファンダメンタルズで説明できない部分」という年次の逸脱である。エピソードの計算可能性も同ゲートで実証済み。再現スクリプトは `~/workspace/round12_run/ws1_leftovers.py`、結果は `ws1_results.json`。

## 信号の固定

残差の構築はゲート計算（ws1_leftovers.py の `episodes_1a` / `ks_residuals`）と同一の手順で固定する。

- **エピソード**: 銘柄ごとに、J-Quants fins キャッシュ（`~/workspace/cache/jquants_exp002/`）のレコードのうち CurPerType = "FY" かつ DocType に "FinancialStatements" を含むもの（FY 短信）を、(DiscDate, DiscTime) 順に並べた列を対象とする。各 FY 短信が1エピソードであり、同じ CurFYEn に複数の FY 短信レコードがある場合は各開示がそれぞれエピソードになる。
- **入力項目**（すべて当該 FY 短信レコード自身の値。「前期」とは予想対象年度から見た前期、すなわちその開示で報告された完了事業年度の実績を指す）:
  - 被説明変数 y = NxFNp / Eq（次期純利益予想 ÷ 期末自己資本）
  - 前期 ROE = NP / Eq（NP は完了事業年度の実績純利益）
  - 前期純利益成長率 g = (NP_t − NP_{t−1}) / |NP_{t−1}|。NP_{t−1} は同一銘柄の FY 短信レコード列で直前にあるものの NP（直前の NP が欠落している場合は、最後に有限だった FY の NP を用いる）
  - log（前期売上高）= log(Sales)（完了事業年度の実績売上高）
  - 赤字ダミー loss = 1{NP_t < 0}
- **スクリーニング**: Eq ≤ 0、NxFNp または NP が有限でない、Sales ≤ 0、g が有限でない（NP_{t−1} が 0 または欠落の場合を含む）のいずれかに該当するエピソードは、回帰からも状態の更新からも除外する。
- **年次横断面回帰**: 開示日（DiscDate）の暦年ごとに、その年のスクリーニング通過エピソード全件で OLS を推定する: y = a + b1·ROE + b2·g + b3·log(Sales) + b4·loss + resid。被説明変数と連続説明変数（y、ROE、g、log(Sales)）は年内で 1/99 パーセンタイルで winsorize してから推定し、**resid = （winsorize 後の y）− 当てはめ値** とする。赤字ダミーは winsorize しない。年内のスクリーニング後件数が 30 未満の年は、その年のエピソード全てを無効とする。
- **有効化（ポイント・イン・タイム）**: resid は開示日の**翌日以降**に有効になり、次の FY 短信開示で新しい resid が有効化されるまで持続する（固定の失効期間は設けない）。入力要件を満たさず resid が付かない FY 開示では状態は更新されず、直前の状態が残る。
- **傾斜成分**: 各日、A の有効集合のうち状態を持つ銘柄について resid をパーセンタイルランク化し（タイは平均ランク）、leg_r = 1 − pct_rank(resid) とする（残差が小さい＝ファンダメンタルズ対比で保守的な銘柄ほど高いランク）。状態を持たない銘柄は中立 0.5。
- **スコア**: A_res = (comp_r + mom_r + leg_r) / 3。ロング・ショートとも標準の simulate（A と同一の仕組み、ショート比率 0.5）。残差の大きい（根拠のない楽観）銘柄がショート側に、残差の負の（保守的）銘柄がロング側に寄る。

## ドラフトからの補完（結果を見る前に固定した事項の開示）

第12弾レポート末尾の事前登録ドラフトを正本とし、信号・閾値・判定基準は変更していない。ただし事前登録として固定が必要な点について、ドラフトが曖昧だった箇所を以下のとおり補完した。いずれもゲート再現スクリプト（ws1_leftovers.py）の実装どおりであり、結果を見た後の変更ではない。

1. **回帰の年次グループは開示日（DiscDate）の暦年**であることを確定した（ドラフトの「開示暦年」を具体化）。
2. **残差は winsorize 後の被説明変数から当てはめ値を引いたもの**と確定した（ドラフトは winsorize の対象と残差の定義を併記していたが、どちらに winsorize 後の値を用いるか曖昧だった）。
3. **30件バーの「件数」は入力スクリーニング後の年別件数**であることを確定した。
4. **成長率の前期 NP_{t−1} の定義**（同一銘柄の FY 短信列で直前の NP、欠落時は最後に有限だった FY の NP、NP_{t−1} = 0 の場合は非有限として除外）を確定した。
5. **説明変数の「前期」は、開示された完了事業年度の実績**であることを明文化した（ドラフト・ゲート実装と一致する解釈の固定）。
6. **エピソード集合の範囲**: ゲートの相関証拠は EXP-080 の癖と重複する部分集合（2,129 件）で計算されたものであるが、本信号のエピソード集合は上記の入力要件を満たす**全 FY エピソード**であり、癖の有無は条件にしない（ドラフトのエピソード定義どおり）。
7. **年次横断面の係数は、その暦年の全エピソードで推定される**。したがって係数の水準には同一年内の後発開示の情報が入り得る（係数レベルのタイミング留保。エピソード自身の入力項目は全てその開示時点で既知である）。この仕様はドラフトおよびゲート証拠の計算と同一であり、証拠との整合のため変更しない。リスク節にも併記する。
8. タイの平均ランク処理、「resid が付かない開示では状態を更新しない」規則を EXP-107 の様式に倣って補完した。

## リスク・留保

- **原論文の留保**: Kitagawa-Shuto 自身の留保どおり、効果は彼らの前期サンプル（2005–06 年ごろ）に集中している可能性が高い。当キャッシュは 2016 年開始でその強い時期を含まない。「文献どおりなら今の期間では弱い」が本命の敗因候補である。
- **多重検定**: 約60番目の挑戦者であり、多重検定の割引が最大級にかかる。薄いマージンの通過は偶然でも起こり得る前提で読む。
- **癖ファミリーとの近接**: 直交性はゲートで実測済み（Pearson +0.038 / Spearman −0.001）だが、同じ「予想の質」を見る家系であることは事実であり、判定では近接性も併記する。
- **モデルの当てはめ方への依存**: 残差は回帰仕様に依存する。仕様は本登録で固定したが、説明変数の選択自体が研究者の自由度であり、仕様を変えた再挑戦は行わない。
- **係数のタイミング**: 年次横断面の係数は同一年の全エピソードで推定され、係数水準に後発開示の情報が入り得る（補完事項7）。エピソード自身の入力は全て開示時点で既知であり、値レベルの先読みはない。
- 残差の大きい銘柄をショートする側には、通常の空売りリスク（借株コスト・踏み上げ）が伴う。
