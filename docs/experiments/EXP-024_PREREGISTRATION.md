# EXP-024 事前登録：ロング側の決算またぎ回避

状態: 計画（未実行）

## 背景・仮説

A のロングブックは20営業日保有の回転であり、保有中に決算発表をまたぐとギャップ（寄り付きの急落・急騰）のリスクを取る。日本の小型・中型株では決算ギャップがドローダウンの主因の一つとされる。決算発表の直前〜直後にその銘柄のロングスコアを無効化し、リバランスで自然に手仕舞い・再エントリー禁止とすれば、利益の大半を保ったまま DD が浅くなる可能性がある。これは後付けのオーバーレイ（EXP-013/019/022 が失敗した類）ではなく、保有ルール側の変更として検証する。

## 方法

- データ: EXP-002 キャッシュ（306 銘柄）。決算日はキャッシュの財務サマリの開示日（DiscDate）をそのまま使う
- 発表を価格が織り込む最初のセッションを iD（開示日の翌営業日）として、**[iD−2, iD] の3営業日**、その銘柄のロングスコアを NaN にする。買い側だけに適用し、空売り側は A のまま不変（EXP-013 の simulate2 で両面を別々に与える）
- 前提の明示: 日本企業は決算発表予定日を事前に公表するため、開示日は近似的に事前に分かるものとして扱う。マスク幅（前2日＋当日）はこの事前登録で固定し、結果を見て変えない
- バリアントは1本のみ。比較対象は A（S も併記）。期間・費用は従来通り
- 診断として、マスクされた銘柄・日の割合を報告する

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- エンジンの仕様上、退出はトランシェのリバランス日にしか起きないため、マスク期間内でもリバランスが来なければまたぎを完全には避けられない（EXP-019 のマスクと同じ限界）
- 決算後の上昇ギャップも同時に捨てることになる（回避は両方向に効く）
- 四半期ごとに全銘柄が対象になるため、マスクの総量が多く、回転の機会損失が大きい可能性
