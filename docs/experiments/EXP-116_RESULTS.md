A のロング簿を EXP-114 と同じトランシェ再現で AGN・X 両方について再現し（フル期間、2017-01-04 開始）、比較した:

- OP のみ旗の旗付き銘柄日のうち AGN のロング簿に入っている割合: **10.64%**（483 日）
- リバランスイベント 1,197 回のうち AGN と X で選択が変わったのは **161 回（13.4%）**。うち入れ替え銘柄集合に OP のみ旗の銘柄が直接含まれたのは **26 回**。残りは保有中銘柄の除外条件を介したカスケード（ペナルティで外れた銘柄が他トランシェの候補順位を変える）である
- 簿の銘柄日ベースでは 1,496 日（AGN 簿 47,500 日の 3.1%）が入れ替わった
- 入れ替わった銘柄のその後 20 営業日超過（TOPIX 対比、記述的な帰属）: 外れた銘柄（AGN のみ、n=178）は平均 **−0.68%**（中央値 −0.66%）、入った銘柄（X のみ、n=178）は平均 **−0.43%**（中央値 −0.23%）。ペナルティはその後劣後する銘柄を確かに外したが、代替銘柄も TOPIX を下回っており、イベント単位の純効果は小さい。最終的な損益差は経路と複利で決まり、前半・後半で符号が分かれた

## 解釈

- 記述段階で OP 旗は NP 旗より強く見えた（−5.10% vs −3.91%）が、その大半は両旗の重なり（352/428 件）が担っており、純粋な増分の OP のみ 76 件は薄かった（前半 30 件、記述でも前半 −1.55%）。ブックテストでは増分は後半でのみ効き、前半では DD を深めて AGN を悪化させた。
- これは「合成は土台対比で落ちる」先例（EXP-100B・102B 等）の再現であり、登録時の見込み（「ブックテストで落ちる可能性は高い」）どおりの結果である。AGN 単独（EXP-114 の NP 旗）が現行の確定形であり、本拡張は採用しない。
- 用量・閾値・対象を変えた再試行は登録外である（両旗銘柄への −0.20 案、OP 閾値 −30% 案はいずれも登録していないため行わない）。
