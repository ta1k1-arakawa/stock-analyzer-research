## 信号の固定

- **エントリー**: **取引日 t の引け価格で売る（ショート）**。前方実装では引け価格をエントリー価格として台帳に記録する。
- **エグジット**: **翌営業日の引け価格**で全量を買い戻す。翌営業日の引け価格が得られない場合は対象外とし、その旨を台帳に記録する。
