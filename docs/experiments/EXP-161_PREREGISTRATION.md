## 実現可能性の記録（必須、EXP-124 / EXP-151 / EXP-157〜160 と同型）

各イベントに次を記録する:

1. **貸借銘柄か否か**（イベント日時点で制度信用で空売り可能か。J-Quants の銘柄マスターを当日分取得して記録する）。
2. **空売り価格規制の該当**（イベント日にトリガー抵触があったか。日足安値プロキシで記録する）。
3. **当日に出来高があること**（引け価格が成立し条件が算出できていることをもって約定成立とし、引け価格が無い日はエントリー自体を行わないことでこの項目を扱う）。
4. **逆日歩の発生有無と金額**（取得可能な場合は実績を記録し差し引く。取得できない場合は「取得不可（unavailable）」と記録して差し引かず、その分だけ判定が楽観側である旨を集計に明記する）。
5. **貸株料の扱い**（制度信用の標準料率 1.15%/年（日本証券金融）ベースの計算値 = 想定元本 × 料率 × 保有暦日数 / 365 を実績記録として残し、差し引く。料率の出典と適用日を集計側に明記する）。

**実行不能の定義と集計**: 1 で貸借銘柄でない、または 3 で引け価格が成立していないイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。
