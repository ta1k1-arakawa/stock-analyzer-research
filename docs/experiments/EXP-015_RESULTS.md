# EXP-015 結果：営業利益ガイダンス上方修正スリーブは不採用（後半は S を上回るも基準未達）

事前登録: `docs/experiments/EXP-015_PREREGISTRATION.md`（33cfc64）
コード: `experiments/exp015_guidance_sleeve.py`（同一キャッシュ `data/jquants_exp002` の生記録と価格、資金200万円、EXP-009 の3基準）

## 健全性チェックと診断

- S の再計算が従来実験と完全一致（前半 +1,034,912／比率 0.302、後半 +2,634,920／1.086、全期間ストレス +4,423,939／0.361）
- 検出イベント総数 1,020 件（うち単独の修正開示 461 件）で、事前確認と一致
- 実行できたイベントは全期間で 376 件。612 件は「同時保有10件の枠が満杯」で見送り（先着順ルールどおり。枠の制約が強く効いた）。実行分のうち単独修正開示は 179 件

## 結果（基本費用、S は同一キャッシュで再計算。TOPIX は候補の元主張との対照として診断表示）

| 期間 | S 損益 / 比率 | スリーブ 損益 / 比率 | TOPIX 損益 |
|---|---|---|---|
| 前半 2017–2021 | +1,034,912 / 0.302（DD −28.9%） | +504,850 / 0.126（DD −36.6%） | +599,189 |
| 後半 2022–2026 | +2,634,920 / 1.086（DD −17.9%） | +2,328,139 / **1.526**（DD −11.6%） | +2,096,616 |
| 全期間 | +6,157,708 / 0.538 | +2,664,619 / 0.248 | +3,386,148 |
| 全期間・ストレス | +4,423,939 / 0.361 | +2,555,684 / 0.237 | — |

## 判定（事前登録の3基準）

- 基準1（両期間とも黒字）: 通過
- 基準2（両期間とも比率が S 超え）: **不通過**（後半は 1.526 vs 1.086 で大きく上回ったが、前半が 0.126 vs 0.302）
- 基準3（全期間ストレスで黒字かつ比率 S 超え）: **不通過**（0.237 vs 0.361）
- **結論: 有望でない。** 候補5のガイダンス編は終了。自社株買い編はデータ理由で未実施のまま（事前登録に記録）

## 解釈（事後の考察。基準・パラメータは変更していない）

- 後半（2022–2026）の強さは本物らしく、ロングのみにもかかわらず S の比率と TOPIX の損益の両方を上回り、ドローダウンも最も浅かった。東証改革以降に上方修正への市場の反応が強まった可能性と整合する
- 一方で前半は TOPIX の損益にも届かず、10銘柄集中のロングのみゆえに下落局面のドローダウンが深い（−36.6%）。全期間ではこの前半の弱さが効いた
- 枠10件の固定ルールで 612 件を見送っており、「枠を広げれば」という誘惑はあるが、それは新しい事前登録なしには試さない。後半だけを切り取って良く見せることもしない
- EXP-010 の A（修正方向を速いブックに薄く混ぜる形）が既に有望判定で運用中であり、ガイダンス修正シグナルの価値はそちらで取り込み済み、という整理もできる
