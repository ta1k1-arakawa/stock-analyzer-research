# EXP-079 結果：第9弾スイープ候補のキルテスト一式

第9弾スイープ（2026-11-03、research_notes/japan-equity-ideas-round9）の
候補 C1〜C7 に、各候補が定めた安価なキルルールを適用した記録。
ユーザーの指示（2026-11-03）により全候補を実施した。

## C1 同業ニュースへの過剰反応の逆張り → キル

2022〜2026 年の遅発開示イベント 1,910 件で、補正リターン対ドリフトの
回帰傾斜は −0.003（実質ゼロ）、|ドリフト| 上位 1/3 の逆張り損益は
−0.250%/件。Kitagawa の過剰反応は近年のデータでは取引可能な形で
存在しない。米国の減衰証拠とも整合。

## C2 主要顧客モメンタム → キル（被覆）

FY2025 波の有報から主要顧客テキストを抽出。ユニバース内顧客を名指し
できる供給者は 11 社のみで基準 25 社未満。Cohen & Frazzini の信号自体は
否定しないが、この 306 銘柄では組めない。

## C3 セグメント加重モメンタム → キル（マッピング不成立）

複数セグメント開示は 140 社で件数基準（60 社）を通過し、セグメント別売上
まで取得した。しかしセグメント名は統制語彙ではなく、FY2025 波で 381 種の
うち 336 種が 1 社だけの単発ラベルで、事業セグメントと地域セグメント
（Japan、China、Europe 等）が同一要素に混在する。Cohen & Lou 型の
「セグメント→業種」対応付けが現実的なコストで作れず、実装可能性の
ゲートでキル。取得データ（セグメント別売上）は保持する。

## C4 公募増資のみ回避 → キル（EXP-033 で測定済み）

EXP-033 の ISS 分類は公募を明示的に含んでおり、提携なし発行（ISS-P）の
+20 日平均超過リターンは +4.10% と、C4 の前提と逆向きで、キル条件
（>−1.0% でキル）に抵触する。新規の測定は不要と判断し、既存証拠で閉じた。

## C5 完全子会社 TOB の残りスプレッド → キル（頻度）

TDnet タイトル上の完全子会社化 TOB は年数件のタイトル数で、同一案件の
続報を除くと実質年 1〜4 件。20 銘柄分散の本には載らない。スプレッドの
測定には開示本文が必要で、その蓄積は別途開始した（下記）。

## C6 予想の癖 → 通過、EXP-080 で PROMISING

初期予想誤差の持続性 ρ=+0.155（基準 0.10）、赤字回避スライスの平均
バイアス +0.417 vs 他 +0.097。EXP-080 として事前登録・ブックテストを
実施し、標準3基準を全て通過（4例目）。フォワード統合は EXP-081。

## C7 信用規制の増担保フラグ → キル（重要性）

前提訂正：日々公表信用データ（/v2/markets/margin-alert）は Standard で
2016 年まで遡れた。増担保（Restricted）フラグの点灯は 10 年で 41 件
（28 銘柄）と件数基準（20 件）は通過したが、年 ~4 件では EXP-033 の
重要性の先例により本に意味を持たない。重なりチェックは行わず閉じた。

## 蓄積アクション（実施済み）

- TDnet 開示本文（PDF）の日次アーカイブを開始。本文は約30日で消えるため、
  公式の日次一覧ページからユニバース銘柄分を毎日保存する
  （初回で 2026-10-05〜11-03 の 300 件を取得、平日夕方の cron で継続）。
- margin-alert の履歴が API で取れることを確認したため、同データの
  スナップショット蓄積は不要。
