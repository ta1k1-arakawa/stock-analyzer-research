# EXP-037 事前登録:夜間/日中の綱引き頻度(ロング側のみのティルト)

状態: 計画(未実行)

## 背景・仮説

文献探索第2弾の第6案。Akbas et al. (2021, JFE、米国株)は、「夜間に上がって日中に下がる」日の頻度が高い銘柄は翌月にアウトパフォームし、その効果はロング側に集中するとした。恒常的に夜間に買う層(個人)と日中に売る層の綱引きで日中価格が過度に押し下げられる、という解釈である。日本株での直接検証は見つかっていない。データは日次の始値・終値だけで足りる。

## シグナル(すべてこの事前登録で固定する)

- 夜間リターン = 当日始値 ÷ 前日終値 − 1、日中リターン = 当日終値 ÷ 当日始値 − 1
- 綱引き日:夜間リターン > 0 かつ日中リターン < 0 の日
- レッグ値:直近 **20 取引日**に占める綱引き日の割合。A の有効集合の中で日次パーセントランク化。有効日が 15 日未満なら中立 0.5
- **ロング側だけ**に効かせる(原論文がそう示すため):ロング用スコア = (comp_r + mom_r + tow_r) / 3、ショート用スコア = A のまま。合成は EXP-013/031 の simulate2 を使う
- 比較対象は A(S も併記)。期間・費用は従来どおり

## 判定基準(A に対する通常の3基準)

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

## リスク・注意(結果を見る前に)

- 日本の寄り付きは米国市場の夜間動向を強く受けるため、「夜間の圧力」がノイズではなく情報である可能性があり、機序が反転しうる(探索レポートの指摘どおり)
- 20 日の頻度は粗い指標で、銘柄間の差が小さく順位が不安定になりやすい
- 米国での効果(+0.92%/月)自体、日本での裏付けがない輸入仮説である
