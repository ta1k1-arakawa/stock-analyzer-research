# EXP-091 計画：EXP-090 の通過3本をフォワードのペーパーで検証する

EXP-089 と同じ手順。EXP-090 で全基準を通過した 3 本を、明日の
ステップからペーパーとして追加し、登録条件つきの再演で相対優位が
フォワードの実行力学でも再現するかを判定する。

- **AF125** = 予想の癖の割引 ×1.25（EXP-090C、全期間利益が
  全挑戦者で最高 +¥8,312,155）
- **AF15625** = AF ×1.5 ＋ ショート比率 0.625（EXP-090A）
- **AVF15** = AF ×1.5 のロングに AV ボーナス +0.10
  （EXP-090B、後半比率 2.151 は全挑戦者で最高）

登録条件（EXP-086/089 と同じ物差し）：再演で
(i) 利益が再演 A 以上、または (ii) DD が再演 A より浅く年次/DD が
再演 A を上回る、のどちらかを満たせば継続の根拠あり。両方とも
満たさなければ「継続の根拠なし」と記録する（削除はしない）。

注意：3 本とも同じ AF レバーの派生であり、独立な発見ではない。
再演は S・A・AF15 と同じ実行で回し、AF15（EXP-089 の再演）と
数値が一致することも確認する。ライブ A と実弾 V は変更しない。
