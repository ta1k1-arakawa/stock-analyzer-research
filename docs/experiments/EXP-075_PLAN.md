# EXP-075 計画: 株主総会の反対票 — 蓄積の開始(第4弾候補7、フォワード専用)

## 位置付け

2017–2026 のバックテストは不可能(臨時報告書の縦覧期間切れ)。本件は実験の実行
ではなく、**データ蓄積の開始と仮説の事前登録**である。実測済みの前提:

- EDINET API で 306 銘柄の臨時報告書(docTypeCode 180)が取得でき、2026-06-26
  の1日だけで対象 38 件、全件 csvFlag=1。
- 議決権行使結果は XBRL→CSV の「株主総会における決議」テキストブロック内に
  候補者別の賛成数・反対数・賛成割合(%)を含む定型表として入っており、機械抽出が
  可能(2026-06-26 の菊水HD 分で確認)。
- 2025 年 6 月の提出分もダウンロード可能(2025-06-27 で確認)。よって 2025・2026
  の 2 シーズンをバックフィルで即時回収でき、以降は週次蓄積で継続する。

## 抽出仕様(固定)

- 対象: 306 銘柄ユニバース、docTypeCode 180 のうち決議テキストブロックを含むもの。
- 取締役選任議案の候補者ごとに賛成割合(%)を抽出し、反対率 = 100 − 賛成割合 とする
  (棄権は分母の扱い上近似として扱う旨を明記)。
- 保存する指標: (a) 代表取締役(DEI の代表者氏名と一致する候補)の反対率、
  (b) 全候補中の最大反対率、(c) 株主提案の有無とその賛成割合。
- 生の CSV zip も archive に保存し、抽出の再検証を可能にする。

## 事前登録する仮説(2シーズン蓄積後に判定)

- H1(圧力有効): 反対率上位群は総会後 12 か月でアウトパフォーム → ロング微チルト候補。
- H2(問題持続): 反対率上位群はアンダーパフォーム → ロング除外/ショート候補。
- **キルルール**: 2シーズン分について、反対率と翌12か月リターンの間に単調な関係が
  どちらの方向にも無ければ廃棄し、それ以上追わない。

## 運用

- バックフィル: 2025-01 以降の日次リストを走査し対象を回収(再開可能な形で実施)。
- 継続蓄積: 週次で直近分のリストを走査する cron を置く。特に総会シーズン
  (5–7月)は欠落が起きないよう走査漏れをチェックする。
- 取引への組み込みは判定後まで行わない。ライブ A・実弾 V は不変。
