# EXP-084 結果：任意開示の「厚み減少」側は記述ゲートでキル

事前登録: docs/experiments/EXP-084_PREREGISTRATION.md
コード: experiments/exp084_voluntary_decrease.py

## 記述ゲートの結果

- 減少フラグ（dVolA ≤ −2）の同時点中央値: **5 銘柄/日**（基準 8 未満）
- フラグ入りの翌20営業日 TOPIX 超過リターン平均:
  前半 −0.544%（n=88）、後半 **+0.041%**（n=128）で符号が一致しない

両条件とも不成立のため、ブックテストには進まなかった。

## 読み取り

増加側（EXP-054）が「経営の能動性」という情報を持つのに対し、減少側は
「前期に一時的に多かった」場合と区別がつかず、頻度も薄い。開示行動の
信号は非対称であり、符号を反転させれば使えるというものではない。
任意開示の方向は増加側のみで確定。ライブ A は変更しない。
