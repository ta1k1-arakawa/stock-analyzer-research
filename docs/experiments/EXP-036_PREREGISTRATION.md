# EXP-036 事前登録:株式分割の発表後ドリフトは 306 銘柄で捕捉できるか(記述的イベントスタディ)

状態: 計画(未実行)。EXP-033 と同じく**合否基準はない**記述的測定。

## 背景

文献探索第2弾の第3案。株式分割の発表後には約10営業日続く価格の持ち上げがあり約30日で消える(大和総研 2023)、分割後の投資単位が1万円以上10万円未満に収まる場合に強い(証券アナリストジャーナル 2023)、とされる。EXP-033 で構築した TDnet タイトル履歴(33,939 件)がそのまま使える。

## データ・分類(固定)

- イベント:タイトルに「株式分割」を含み、「訂正」「中止」「基本方針」を含まないもの。同日・同銘柄の重複は1件に数える = **106 件**(前半 62 / 後半 44、68 銘柄)。なお「定款の一部変更」は分割に必ず伴う定型句なので除外語にしない
- 価格は EXP-002 キャッシュ

## 測定(固定)

- エントリー:開示日の**翌取引日の寄り付き**でロング。+5 / +10 / +20 取引日の終値までの対 TOPIX 超過リターン(EXP-033 と同じ規約)
- 全体と前半/後半別に、平均・中央値・上昇した割合を報告する
- 参考の切り分け:発表前日の投資単位(終値×100株)が 50 万円以上の銘柄と未満の銘柄を分けて併記する。分割比率はタイトルに無いため、文献の「分割後の単位」条件は厳密には再現できない — これは留保として明記する
- 解釈の事前宣言:+10 日の平均超過が **+1% 未満**なら、このユニバースではスリーブ不成立と結論する。+1% 以上かつ中央値も正なら、スリーブ実験として別途事前登録し直す

## リスク・注意

- 分割は「既に値上がりした銘柄」が発表しがちで、発表前の上昇の反動と混ざる
- 件数は EXP-033 より多いが、それでも統計的検定ではなく規模の確認である
