## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: 取引日 t について、**close_t / prev_close_t − 1 ≥ +0.02 かつ close_{t−1} / prev_close_{t−1} − 1 ≥ +0.02**（2営業日連続で前日比 +2% 以上）を満たす銘柄・日をイベントとする。同一銘柄・同一日は最大1イベント。分割疑い日、必要な価格が得られない日は対象外。3日以上連続した場合も、条件を満たす各日がそれぞれ1イベントになる（記述と同一）。
- **エントリー**: **取引日 t の引け価格で売る**。前方実装では引け後の判定でよいため、記述と同一の引け価格をエントリー価格として台帳に記録する。
- **エグジット**: **翌営業日の引け**で全量を買い戻す。翌営業日が暦日で10日を超える場合は対象外（記述と同一）。引け価格が得られない場合は、引け価格が得られる最初の後続営業日に繰り延べ、その旨と逆日歩の実績を台帳に記録する。
- **価格**: 損益率は未調整価格どうしの比率とする。保有期間中に株式分割・併合の効力が発生したイベントは、調整済み価格ベースの比率を正として併記する。
- **ベンチマーク**: 各イベントについて、同窓（エントリー日引け→翌営業日引け）の TOPIX 変化率を記録し、超過リターン = イベント損益率 + 同窓 TOPIX 変化率（ショートのため）とする。同窓 TOPIX が取得できない場合は、寄付→翌営業日引けの TOPIX 変化率で代用し、その旨を記録する。

## サイジングと台帳（イベント台帳型、EXP-120 / EXP-124 / EXP-129 / EXP-132 と同型）

- **枠**: フォワード共通の予算 ¥400,000 を記録上の枠とする。ペーパーであり実資金は動かさない。
- **1 イベントの金額（想定元本方式）**: 1 イベント = **¥20,000 の想定元本**、株数は 20,000 / 引け価格 で**端数株を許容**する。

## 実現可能性の記録（必須、EXP-124 / EXP-129 / EXP-132 と同型）

各イベントに次を記録する:

1. **貸借銘柄か否か**（イベント日時点で制度信用で空売り可能か）。
2. **空売り価格規制の該当**（イベント日にトリガー抵触があったか）。
3. **引け時点の約定可能性**（当日に出来高があったか）。
4. **逆日歩の発生有無と金額**（日をまたぐ保有のため現実の論点。発生した場合は1株あたり金額を追記で記録）。
5. **貸株料の扱い**（標準料率ベースの計算値を実績記録として残し、料率の出典と適用日を明記）。

**実行不能の定義と集計**: 1 で貸借銘柄でない、または 3 で当日に出来高が無いイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。
