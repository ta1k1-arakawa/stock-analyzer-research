## 背景（結果を見る前に分かっていたこと）

EXP-008 の前に調べた順位別の成績で、合成スコアの下位（81位以下）は、前半 −0.30%、後半 −0.72%（20営業日の超過）と、両方の期間で負けていた。
この案は、その表を見た後に考えた。

## 案（LS）

- 資金 200万円
- 買い：R と同じ（合成スコアの上位、20銘柄、10組、2営業日ごとに1組、各組20営業日保有、寄成）。買いの金額は資産全体
- 空売り：合成スコアの**下位**から同じ仕組みで20銘柄（10組×2）。空売りの金額は、入れ替えの時点の資産全体の50%を10組で等分
  - 対象は買いと同じ条件（流動性1億円以上など）を満たす銘柄。空売りできるか（貸借銘柄か）はデータがないため確認しない
- 費用：売買は片道0.03%（ストレス0.10%）。空売りの保有費用（貸株料と、空売り中に支払う配当の見込み）は年3%（ストレス年5%）
- 買いの配当は含めない（保守的）

参考（判定に使わない）：N ＝ 買い100万円・空売り100万円（残り100万円は現金）

## 判定（前半 2017-01-04..2021-12-30 と 後半 2022-01-04..2026-09-25）

次をすべて満たせば「有望」とし、EXP-004 の前向き検証にペーパーとして加える（実際のお金で使うかは人間が決める）。

1. 両方の期間で、基本費用の LS の損益 > 0
2. 両方の期間で、LS の「年率 ÷ 最大ドローダウンの大きさ」が R（200万円・買いだけ）より大きい
3. 全期間（2017-01-04..2026-09-25）のストレス費用でも、LS の損益 > 0 かつ 2 の比が R より大きい

損益そのものが R を上回ることは求めない（空売りで相場全体の上昇分の一部を手放すため）。代わりに、損失の大きさに対する効率で比べる。
