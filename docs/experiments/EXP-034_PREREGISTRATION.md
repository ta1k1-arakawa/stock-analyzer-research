# EXP-034 事前登録:決算サプライズ(SUE)を A のティルトにする

状態: 計画(未実行)

## 背景・仮説

EXP-018 では決算サプライズ(実績 NP が直前の会社予想を +10% 以上上回る)を独立スリーブにし、前半は強く(比率 0.596)後半は弱かった(0.346)。今回は発想を変え、サプライズを A の中の連続ティルトとして使う。EXP-024 で「決算を跨いで持つ方がよい(開示後ドリフトを A は既に拾っている)」ことが示唆されており、サプライズの方向でドリフトを強めれば A の精度が上がる可能性がある、というのが仮説である。

## シグナル(すべてこの事前登録で固定する)

- サプライズの計算は EXP-018 の機械をそのまま使う:開示順に会社予想を追跡し、FY は当該年度の FNP、2Q は FNP2Q に対し、実績 NP(売上と NP の両方が載ったレコード)との比 −1 を取る。予想が 0 以下の場合は使わない
- レッグ値:各銘柄の**直近の FY/2Q 決算開示のサプライズ(符号付き連続値)**。開示日から **90 暦日**有効。それ以外は中立 0.5
- A の有効集合の中で日次パーセントランク化し、**A_sue = (comp_r + mom_r + sue_r) / 3**
- 閾値版(+10% 以上のときだけ正のレッグ)は作らない(バリアントの増殖を避ける)。比較対象は A(S も併記)、期間・費用は従来どおり

## 判定基準(A に対する通常の3基準)

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

## リスク・注意(結果を見る前に)

- 修正モメンタム(予想の変化)と SUE(実績 vs 予想)は同じ決算ニュースの別側面であり、相関して新規性が薄い可能性がある
- EXP-018 のスリーブは時期で符号が反転した(前半強・後半弱)。ティルトでも同じ反転が起きれば基準2で落ちる
- 90 日の有効期間は四半期決算の間隔に合わせたもので、調整はしない
