# EXP-085 結果：部分セクター中立化は記述ゲートでキル（前提がデータに無い）

事前登録: docs/experiments/EXP-085_PREREGISTRATION.md
コード: experiments/exp085_sector_gate.py

## 記述ゲートの結果

- (a) 発動日割合: 18.3%（基準 10〜40% の範囲内）→ 通過
- (b) ファクター冬エピソード中の業種乖離: 平均 0.1426、
  平常時 0.1712 より**小さい** → 不成立

前提である「ファクター冬では A の業種エクスポージャーが極端になる」
がデータに存在しないため、ブックテストには進まなかった。

## 読み取り

2021年秋・2026年春のファクター冬で沈んだのは業種の偏りではなく、
業種内での銘柄選択（バリュー／予想系ファクターそのものの逆風）だった
と読める。セクター中立化の方向は EXP-022 と合わせて完全に閉じた。
ライブ A は変更しない。
