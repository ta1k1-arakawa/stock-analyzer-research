## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: 取引日 t について、**close_t / prev_close_t − 1 ≤ −0.02 かつ close_{t−1} / prev_close_{t−1} − 1 ≤ −0.02**（2営業日連続で前日比 −2% 以下）を満たす銘柄・日をイベントとする。同一銘柄・同一日は最大1イベント。分割疑い日、必要な価格が得られない日は対象外。3日以上連続した場合も、条件を満たす各日がそれぞれ1イベントになる（記述と同一）。
- **エントリー**: **取引日 t の引け価格で買う**。前方実装では引け後の判定でよいため、記述と同一の引け価格をエントリー価格として台帳に記録する。
- **エグジット**: **翌営業日の引け**で全量を売る。翌営業日が暦日で10日を超える場合は対象外（記述と同一）。引け価格が得られない場合は、引け価格が得られる最初の後続営業日に繰り延べ、その旨を台帳に記録する。
- **価格**: 損益率は未調整価格どうしの比率とする。保有期間中に株式分割・併合の効力が発生したイベントは、調整済み価格ベースの比率を正として併記する。
- **ベンチマーク**: 各イベントについて、同窓（エントリー日引け→翌営業日引け）の TOPIX 変化率を記録し、超過リターン = イベント損益率 − 同窓 TOPIX 変化率（ロングのため）とする。同窓 TOPIX が取得できない場合は、寄付→翌営業日引けの TOPIX 変化率で代用し、その旨を記録する。
