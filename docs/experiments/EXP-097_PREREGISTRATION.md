# EXP-097 事前登録：営業利益予想の「癖」— 予想の信用を4つ目の道具で測る

根拠：EXP-080（純利益予想の癖）は通過し、EXP-092（配当予想の癖）は
材料不足で落ち、EXP-093（売上高予想の癖）は前半が 0.337 vs A 0.348 の
僅差で落ちた。営業利益予想は残る4つ目の道具で、全社が開示する。
癖の測定が「予想の信用」という一貫した性質を捉えているなら、
営業利益でも効くはずである。

## 記述ゲート（実行前に測定済み、2026-11-06）

- 初期予想誤差の持続性 Spearman ρ = **+0.286**（n=2,043、p≈1e-39）。
  EXP-080 の純利益 +0.155 を大きく上回り、癖ファミリーで最強。
  ゲート基準 0.10 を通過。
- 平均バイアス +0.152（初期予想は楽観的、EXP-080 の +0.108 と同方向）。
- エピソード 2,043 件。ペナルティ対象の同時点中央値 **12 銘柄/日**
  （habit > +0.03；+0.10 でも 11 銘柄/日）。ゲート基準 5 を通過。
  （EXP-093 売上：10 銘柄/日・2,134 件、EXP-092 配当：3 銘柄/日でゲート未達）

## 定義（EXP-093 と同じ骨格、物差しだけ営業利益用）

- 翌期の初期営業利益予想 = FY 短信の NxFOP、その期の実績 = 翌年 FY
  短信の OP（0 でない場合のみ）。
- 年次バイアス = (初期予想 − 実績) / |実績|、±2 で winsorize
  （EXP-080 の純利益と同じ形。営業利益は利益系でブレが大きいため
  売上の ±0.5 ではなく ±2）。
- habit = 直近3期分の平均（2期以上必要）。
- エピソード窓：FY 短信の開示日から、その営業利益予想（FOP）が
  変更される次の開示、または3か月の早い方。
- 窓の間、habit > +0.03 の銘柄にロング側 −0.10。ショート側は不変。
- 変種はこの1本だけ。

## 判定

標準3基準（対 A）：(1) 前半・後半とも base コストで利益プラス、
(2) 前半・後半とも年率/DD 比率が A を上回る、(3) 全期間 stress で
利益プラスかつ比率が A を上回る。3つ全て通過で有望とし、次段は
フォワードのペーパー統合と再現検証。ライブ採用ではない。
約48本目の挑戦者であり、多重検定の割引が効く。
