# EXP-032 事前登録：流動性ショックへの過小反応ティルト

状態: 計画（未実行）

## 背景・仮説

文献探索第2弾（2026-11-01）の第1案。Iwanaga & Hirose (2022, Pacific-Basin Finance Journal) は全上場銘柄・1995–2020 年で、流動性が予想外に改善した銘柄（正の流動性ショック）はその後のリターンが高いこと、すなわち市場が流動性の変化に過小反応することを示した。米国と違い日本では非流動性そのものが過小反応の駆動力とされる。価格の水準でも流動性の水準でもなく「流動性の変化」を見る点で、これまでの全実験と直交する。日次データだけで計算できる。

## シグナル（すべてこの事前登録で固定する）

- 日次非流動性: ILLIQ(d) = |日次リターン| ÷ 売買代金(d)（売買代金 > 0 の日のみ有効）
- ショック: **shock(d) = ln(ILLIQ の平均, 区間 [d−249, d−20]) − ln(ILLIQ の平均, 区間 [d−19, d])**。正 = 直近20日の非流動性が、それ以前230日の自社ノルムより低い（流動性が改善した）
- 有効条件: 短期窓に有効日 15 日以上、長期窓に 150 日以上。満たさない銘柄は中立 0.5
- レッグ: A の有効集合の中で shock を日次パーセントランク化
- **A_liq = (comp_r + mom_r + shock_r) / 3**。比較対象は A（S も併記）。期間・費用は従来通り

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- 論文自身の機序（非流動性が過小反応を生む）によれば、流動性の高い 306 銘柄では効果が最も弱くなるはずであり、消えても不思議はない
- ショックは短期リバーサルや出来高急増と紛れる可能性がある
- 2017 年初は長期窓（250日）の都合でシグナルが薄く、前半の序盤は中立が多い
