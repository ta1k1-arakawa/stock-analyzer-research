# EXP-101 計画：EXP-100 の通過 3 本をフォワードのペーパーとして追加し、再演で判定する

登録日: 2026-11-07
対象: EXP-100 で宣言済み基準を通過した 3 本。100B（ABGF15）は不採用の
ため追加しない。ライブ A と実弾 V は変更しない。

## 追加するペーパー

| 名前 | 構成 | 土台 |
|---|---|---|
| AVF625 | AVF15 のスコア（予想の癖 ×1.5＋任意開示 +0.10、ショートは AF15 スコア）× ショート比率 0.625 | EXP-100A（標準基準通過） |
| AV625 | AV のスコア（A＋任意開示 +0.10、ショートは A）× ショート比率 0.625 | EXP-100C（標準基準通過） |
| ABD | A のロングに大量保有の減少イベント（type-2 で 1pt 以上減少）後 120 日間 −0.10、ショートは A | EXP-100D（ゲート通過＋適応基準通過） |

## フォワード側の変更

- exp004_forward.py: PORTFOLIOS に 3 本を追加、SHORT_FRAC_BY に
  AVF625 / AV625 = 0.625、load_state 初期化、注文シート表題、
  ショート側の従属（AVF625 は AF15 スコア、AV625・ABD は A）。
- ABD 用に減少イベントのフィードを新設：forward/decrease_events.csv
  （アーカイブから 300 件を名寄せシード）、update-data に
  update_decrease_events（J-Quants 大量保有 API の日次取得、失敗しても
  既存イベントを保持）、decrease_flags（120 日窓）。
- 開始は次回ステップ（2026-11-09）から。

## 再演による判定（登録条件）

期間 2022-01-04〜2026-09-25、予算 ¥400,000、EXP-055 系ハーネス。
ポートフォリオ: S / A / AV / AVF15 / AB / AVF625 / AV625 / ABD。

新規ペーパーごとに、対 再演 A で：
- (i) 再演損益が再演 A 以上、または
- (ii) 最大 DD が再演 A より浅く、かつ年次/DD 比率が再演 A を上回る

どちらかを満たせば「観測を続ける根拠あり」、両方とも満たさなければ
「観測を続ける根拠なし」と記録する（ペーパーは撤去しない）。
check 1（再演 A がスケール済みバックテスト A +¥832,137 の ±5% 以内）は
既知の「フォワードが熱く出る」パターンで不通過が通常であり、記録のみで
判定の物差しは相対条件 (i)/(ii)。
土台との比較（AVF625 vs AVF15、AV625 vs AV）は観測として併記し、
登録条件にはしない。

## 留保

- ABD のブックテスト通過は適応基準（後半のみ）であり、標準通過の
  2 本より弱い。再演でも同じ温度で読む。
- 通過は採用ではない。判定は再演＋今後のフォワード実績が持つ。
