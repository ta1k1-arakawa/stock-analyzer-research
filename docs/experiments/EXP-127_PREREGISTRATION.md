## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: 取引日の **10:00 時点**で、10:00の1分足終値 p1000 と、寄り付きから10:00までの VWAP（出来高加重平均価格、特徴量 vwap1000）について **p1000 / vwap1000 − 1 ≥ +0.02** を満たす銘柄・日をイベントとする。同一銘柄・同一日は最大1イベント。分割疑い日、p1000 または vwap1000 が得られない日は対象外。
- **エントリー**: **10:00の1分足終値（p1000）で売る**。前方実装では10:00直後の実約定価格ではなく、記述と同一の p1000 をエントリー価格として台帳に記録する（実フィードでの観測価格との乖離は観測項目として残してよいが、判定は p1000 ベースで固定する）。
- **エグジット**: **当日の引け**で全量を買い戻す。引け価格が得られない（売買停止等）場合は、引け価格が得られる最初の後続営業日に繰り延べ、その旨と逆日歩の実績を台帳に記録する。
- **価格**: 損益率は未調整価格どうしの比率とする。当日中に株式分割・併合の効力が発生したイベントは、調整済み価格ベースの比率を正として併記する。
- **ベンチマーク**: 各イベントについて、同窓（10:00→当日引け）の TOPIX 変化率を記録し、超過リターン = イベント損益率 + 同窓 TOPIX 変化率（ショートのため）とする。同窓 TOPIX が取得できない場合は、寄付→引けの TOPIX 変化率で代用し、その旨を記録する。

## 実現可能性の記録（必須、EXP-124 / EXP-125 と同型）

各イベントに次を記録する:

1. **貸借銘柄か否か**（イベント日時点で制度信用で空売り可能か）。
2. **空売り価格規制の該当**（イベント日にトリガー抵触があったか。10:00時点の価格での売りは規制の対象になり得るため、該当の有無を必ず残す）。
3. **10:00時点の約定可能性**（当該1分足に出来高があったか）。
4. **逆日歩の発生有無と金額**（買い戻しが翌日以降に繰り延べになった場合のみ）。
5. **貸株料の扱い**（標準料率ベースの計算値を実績記録として残し、料率の出典と適用日を明記）。

**実行不能の定義と集計**: 1 で貸借銘柄でない、または 3 で当該1分足に出来高が無いイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。

- **結論の規則（固定）**: 最終判定で、判定主軸の集計について次の全てを満たす場合に「本実験の主張を前方データが支持した」とする。
  1. 平均損益率がプラス。
  2. TOPIX 超過リターンの平均がプラス。
  3. 中央値が −0.50% 以上。

- **同一データ問題（最重要の割引）**: 本候補の記述数字は、EXP-4 の画面群と同じ2年間の特徴量での再計算であり、独立証拠ではない。本日だけでも分足系のレンズが多数試されており（EXP-125 / EXP-126 の登録を含む）、多重検定の割引は強い。効果量（net +0.64〜+1.07%）は物差しを超えるが、前方検証なしに実弾根拠にはならない。本ペーパーが初の独立判定である。

- **閾値の選択について**: ≥+1.5% と ≥+2% の2形を同一ランで測定し、流動監査を通過した ≥+2% のみを登録した。この選択自体が1段の追加選択であることを明記する。登録後の閾値変更は amendment でも行わない（別実験として起草する）。
