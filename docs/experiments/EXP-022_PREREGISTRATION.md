# EXP-022 事前登録：A の業種中立化（セクター内ランク）

状態: 計画（未実行）

## 背景

EXP-013 では業種中立化を「EXP-002 キャッシュに業種フィールドがない」ため見送った。EXP-021 で J-Quants 接続が使えるようになり、銘柄マスタから TOPIX-17 業種（S17）が取得できるようになったため、未消化だったこの検証を行う。306 銘柄の S17 は 2026-10-29 時点のマスタで 304 銘柄、残り2銘柄（1948 弘電社、9691 両毛システムズ）は 2024-06-28 時点のマスタから補完し、全 306 銘柄をカバーした（experiments/exp022_sectors.json）。

## 仮説

A の横断ランクは業種の偏りを許す（最大業種「情報通信・サービスその他」は 87/306 銘柄）。各レッグを業種内でランク付けし直すことで、ブックが業種横断に分散し、この戦略群の律速であるドローダウンが浅くなる可能性がある。

## 方法

- データ: EXP-002 キャッシュ（306 銘柄）。A・S は同一キャッシュで再計算する
- 業種: S17 を全期間固定で使う（時点情報ではない。再分類は稀という前提を明示する）
- レッグの素点は本番と同一に計算する（B/P と予想 ROE は exp003 の signals、修正モメンタムは exp010 のイベント集計）
- **A_neutral**: 各営業日・各レッグについて、A で有効な銘柄集合の中で S17 業種ごとの百分位ランクに置き換え、A と同じく (composite + mom)/2 とする。それ以外（上位/下位20、1.0/0.5、費用）は不変
- バリアントは A_neutral の1本のみ。比較対象は A（S も併記）

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- 業種は固定割り当てであり、過去の再分類を反映しない
- 小さい業種（電気・ガス 3銘柄、エネルギー資源 3銘柄など）では業種内ランクが粗くなる
- TOPIX-17 の「情報通信・サービスその他」は 87 銘柄と大きく、この分類自体の中立化は部分的になる
- 業種内ランクは業種間の相対的な割安/割高の差を捨てるため、シグナルが業種間に宿っていた場合は損益が落ちる
