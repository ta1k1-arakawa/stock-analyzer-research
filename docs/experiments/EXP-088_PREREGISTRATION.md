# EXP-088 事前登録：大量保有の買い増し追随を「全 filers」に広げる

根拠（内部証拠）：EXP-052 は「重要提案ありのアクティビスト」に限って
通過した（適応基準）。届出行動という信号族そのものは再現済みの系統に
属する。未検証なのは幅である：重要提案の条件を外し、type 1（新規）
または type 2 で比率 +1pt 以上の全ての大量保有届出を対象にしたら、
追随効果は残るか。

## 定義

EXP-052 の flag_matrix から ImpProp 条件だけを外す。フラグは提出日の
翌営業日から 120 暦日。ロング側に **+0.10** のソフトなボーナス
（EXP-052 の +0.15 より弱く、AV と同じ用量）。ショート側は不変
（EXP-052 のショート除外は付けない：031/042 の教訓と、ソフト化の統一）。

## 判定（EXP-052 と同じ適応基準、アーカイブのカバーが 2021-07 以降のため後半のみ）

1. 後半 base で利益がプラス
2. 後半 年率/DD 比率が A を上回る
3. 後半 stress で利益がプラス、かつ比率が A を上回る

イベント数が EXP-052 の 72 件から大きく増えない場合（目安 3 倍未満）は
「幅が広がらなかった」として結果に記録する。
