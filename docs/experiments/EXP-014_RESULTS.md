# EXP-014 結果：残差モメンタムの月次スリーブは不採用

事前登録: `docs/experiments/EXP-014_PREREGISTRATION.md`（255c4c7）
コード: `experiments/exp014_residual_momentum.py`（同一キャッシュ `data/jquants_exp002`、資金200万円、EXP-009 の3基準、エンジンは EXP-010 の simulate_monthly を流用）

## 健全性チェックと診断

- S の再計算が EXP-010／012／013 と完全一致（前半 +1,034,912／比率 0.302、後半 +2,634,920／1.086、全期間ストレス +4,423,939／0.361）
- フルブック（適格40銘柄以上）が組めた月: 121か月中 114か月。最初のフルブックは 2017-05（事前登録で予告した現金期間どおり）。リバランス日の適格銘柄数は平均 265
- スコア（残差の t 統計）の行方向の標準偏差の平均は 0.044

## 結果（基本費用、S は同一キャッシュで再計算）

| 期間 | S 損益 / 比率 | スリーブ 損益 / 比率 |
|---|---|---|
| 前半 2017–2021 | +1,034,912 / 0.302（DD −28.9%） | +907,210 / **0.312**（DD −25.0%） |
| 後半 2022–2026 | +2,634,920 / 1.086（DD −17.9%） | +515,321 / 0.138（DD −36.1%） |
| 全期間 | +6,157,708 / 0.538 | +438,623 / 0.047（DD −43.5%） |
| 全期間・ストレス | +4,423,939 / 0.361 | **−215,991** / −0.019（DD −60.3%） |

## 判定（事前登録の3基準）

- 基準1（両期間とも黒字）: 通過（基本費用では前半・後半とも黒字）
- 基準2（両期間とも比率が S 超え）: **不通過**（前半は 0.312 > 0.302 で上回ったが、後半が 0.138 vs 1.086 と大きく劣る）
- 基準3（全期間ストレスで黒字かつ比率 S 超え）: **不通過**（ストレスで赤字）
- **結論: 有望でない。** 候補4は終了

## 解釈（事後の考察。基準・パラメータは変更していない）

- 前半（2017–2021）は現金期間のハンデがありながら S の比率を僅かに上回り、残差モメンタム自体は日本で死んではいなかった。崩れたのは後半（2022–2026）で、特にストレス時のドローダウン −60.3% は、ショート側の踏み上げか、ファクター・ローディングの変化に固定ベータの残差がついていけなかった可能性を示す（事前登録で引いた Ehsani–Linnainmaa 型の批判と整合的）
- 留保: 本実験はデータ制約で文献標準（月次36か月推定・12か月形成）ではなく短縮版（日次120営業日推定・約5か月形成）である。文献標準そのものを否定する結果ではない。ただし標準版は価格履歴が 2016-10 開始のため通常の評価期間が組めず、試すなら評価期間から設計し直す別実験になる。本実験の窓をいじっての再挑戦はしない
