登録日: 2026-11-07
対象: EXP-102 で宣言済み基準を通過した 3 本。102B（AVF625D）は土台対比で
不採用のため追加しない。ライブ A と実弾 V は変更しない。

## フォワード側の変更

- exp004_forward.py: PORTFOLIOS に 3 本を追加（計 32 本）、SHORT_FRAC_BY に
  ABD625 = 0.625、load_state 初期化、注文シート表題、ショート側の従属
  （ABD625・ABDG は A、ASH は専用の ASH_s ブレンド順位）。
- decrease_events.csv に strong 列を追加（EXP-099 の broad_events と同じ
  後方互換方式）。既存シード 300 件はアーカイブの減少幅で再分類済み
  （strong 61 件、全件照合）、update_decrease_events は取得時に
  減少 ≥3pt を strong として分類し、列を保持する。decrease_bonus（段階化
  ペナルティ）を新設。ABD の decrease_flags は無変更。
- ASH の癖は fc_episodes_today の係数（1 + clip 済み habit）から復元し、
  ブックテストと同一の配合（(a_r + (1 − h_r)) / 2）を毎ステップ計算する。
- 開始は次回ステップ（2026-11-09）から。

## 再演による判定（登録条件）

期間 2022-01-04〜2026-09-25、予算 ¥400,000、EXP-055 系ハーネス。
ポートフォリオ: S / A / ABD / ABD625 / ABDG / ASH。

新規ペーパーごとに、対 再演 A で：
- (i) 再演損益が再演 A 以上、または
- (ii) 最大 DD が再演 A より浅く、かつ年次/DD 比率が再演 A を上回る

どちらかを満たせば「観測を続ける根拠あり」、両方とも満たさなければ
「観測を続ける根拠なし」と記録する（ペーパーは撤去しない）。
check 1（再演 A がスケール済みバックテスト A +¥832,137 の ±5% 以内）は
既知の「フォワードが熱く出る」パターンで不通過が通常であり、記録のみで
判定の物差しは相対条件 (i)/(ii)。
土台との比較（ABD625・ABDG vs ABD）は観測として併記し、登録条件にはしない。

## 留保

- ABD625・ABDG のブックテスト通過は適応基準（後半のみ）であり、
  標準通過の ASH より弱い。再演でも同じ温度で読む。
- ABDG はブックで ABD を上回らなかった。通過の根拠は対 A の宣言基準のみで、
  ABD との差の観測が主目的。
- ASH は DD 主張型の通過（利益は前半・全期間で A 以下）。第10弾の知見では
  DD 主張は再演で再現しやすい側だが、判定は再演が持つ。
- EXP-102 の開示どおり、ブックの比較対象は 2026-11-07 トップアップ後の
  現キャッシュで再計算した A である。再演 A はフォワード側データで
  独立に計算されるため、この点は再演判定には影響しない。
- 通過は採用ではない。判定は再演＋今後のフォワード実績が持つ。
