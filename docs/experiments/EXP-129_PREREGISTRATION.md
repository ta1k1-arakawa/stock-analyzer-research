## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: 取引日に、分足の高値 mhigh・安値 mlow・寄付価格について **(mhigh − mlow) / 寄付 ≥ 0.08** を満たす銘柄・日をイベントとする。同一銘柄・同一日は最大1イベント。分割疑い日、高値・安値が得られない日は対象外。
- **エントリー**: **当日の引け価格で売る**。イベントの検出は前場終了後のスナップショットで行う（「開始の定義」および下記の検出方法の注記参照）が、エントリー価格は日足の終値そのものとして台帳に記録する。イベント日に引け価格が得られない（売買停止等で終値が無い）場合は、エントリー自体を行わず、その旨を台帳に記録する（missed_no_close。当日の…引けでのエントリーが記述の形であるため、翌日以降へ繰り延べてエントリーすることはしない）。
- **エグジット**: **翌営業日の引け**で全量を買い戻す。翌営業日がイベント日から暦日で10日を超えて先になる場合は対象外とする（記述フレームの規則と同一。その旨を台帳に記録する）。翌営業日の引け価格が得られない場合は、引け価格が得られる最初の後続営業日に繰り延べ、その旨と逆日歩の扱いを台帳に記録する。
- **価格**: 損益率は未調整価格どうしの比率を併記し、保有期間中に株式分割・併合の効力が発生したイベントは、調整済み価格ベースの比率を正（主）とする（姉妹実験と同型）。
- **ベンチマーク**: 各イベントについて、保有窓に対応する TOPIX 変化率を記録し、超過リターン = イベント損益率 + TOPIX 変化率（ショートのため）とする。TOPIX の窓別（引け→翌引け）の変化率は取得できないため、実装ではイベント日の寄付→エグジット日の引けの変化率で代用し、その旨（fallback_open_close）を台帳に明記する。
- **検出方法の注記**: mhigh / mlow は、正本と定める記述特徴量（exp4_features.csv）の定義どおり、**前場（Time ≤ 11:30、前場引けのオークションのバーを含む）のバーの高値・安値**である（全日の高値・安値ではない。記述数値はこの定義でのみ再現し、全日定義では 2,763 件・前半 +0.510% / 後半 +0.940% と別の信号になる）。前方では平日 11:37（前場終了後）に当日分足を取得して mhigh / mlow を計算し、イベントを記録する。記述フレームの「全日で5本未満のバーしかない銘柄・日は除外する」という規則は 11:37 時点では判定できないため、前方検出では「前場バーが1本以上あること」を条件とし、前場バー数を監査用に記録する（前場5本以上を条件にすると、記述で登録イベントに含まれる実在ケースを誤って除外することを実測で確認済み。残る継ぎ目は、全日で5本未満に終わるほぼ無取引日を前方では記録し得るという一方向のもので、無視できる水準と判断する）。

## サイジングと台帳（イベント台帳型、EXP-120 / EXP-124 / EXP-125 / EXP-127 / EXP-128 と同型）

- **枠**: フォワード共通の予算 ¥400,000 を記録上の枠とする。ペーパーであり実資金は動かさない。
- **1 イベントの金額（想定元本方式）**: 1 イベント = **¥20,000 の想定元本**、株数は 20,000 / エントリー価格（当日の…引け）で**端数株を許容**する。
- **実弾充足率の観測**: 各イベントについて エントリー価格 × 100 株（単元額）を観測項目として台帳に残す。ペーパーの採否・損益には影響しない。
- **同時保有**: 上限は設けない。同日に複数イベントが発生し得るが、全イベントを独立に記録する。
- **台帳**: イベントごとに、イベント日、コード、寄付価格、mhigh、mlow、レンジ rng、当日の売買代金、株数（端数株）、単元額（観測項目）、エントリー日と引け価格、エグジット日と引け価格（繰り延べた場合はその旨と理由）、分割係数、TOPIX 変化率とその代用の別、コスト別の損益（下記）、次項の実現可能性フィールド、およびイベント日の開示有無（観測項目、判定には使わない）を記録する。台帳は追記のみとし、記録済みの事実は遡及修正しない（未決済イベントの決済情報は同一行への記入で完結させる）。

## 実現可能性の記録（必須、EXP-124 / EXP-125 / EXP-127 / EXP-128 と同型）

各イベントに次を記録する:

1. **貸借銘柄か否か**（イベント日時点で制度信用で空売り可能か。J-Quants の銘柄マスターを当日分取得して記録する）。
2. **空売り価格規制の該当**（イベント日にトリガー抵触があったか。前場のバーの実測（前日終値の90%以下に触れたか）と、日足安値によるプロキシの両方を記録する。引けでの売りは規制価格を下回らない建て方になるのが通常だが、抵触の有無自体を実測として残す）。
3. **引けオークションの約定可能性**（エントリーは当日の引けであるため、イベント日に引け価格が存在することをもって約定成立とし、引け価格が無い日はエントリー自体を行わない（上記の missed_no_close）ことでこの項目を扱う）。
4. **逆日歩の発生有無と金額**（本実験は一晩保有するため逆日歩が実際に発生し得るが、日次の逆日歩フィードが現行の接続範囲に無いため「取得不可（unavailable）」と記録し、実績コスト後からも差し引かない。この分だけ実績コスト後は楽観側に寄ることを留保として明記する。将来フィードが引けるようになれば、台帳への追記で補う）。
5. **貸株料の扱い**（制度信用の標準料率 1.15%/年（日本証券金融）ベースの計算値 = 想定元本 × 料率 × 保有暦日数 / 365 を実績記録として残し、料率の出典と適用日（2026-11-16 から）を集計側に明記する）。

**実行不能の定義と集計**: 1 で貸借銘柄でないイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。

## コストモデル

- **売買手数料**: (a) 片道 0.05%（主軸、記述と同一）、(b) 片道 0.10%（stress）の2建てで記録する。

## 判定（フォワード専用、固定）

- **中間集計**: 最初の **50 件の完了イベント**が揃った時点で、勝率、平均損益率、中央値、TOPIX 超過リターンの平均、実行不能率を集計して記録する。中間集計では採否の結論は出さない。記述密度（306 銘柄で月約59件）からは 50 件完了は開始から 1 か月前後と見積もるが、前方記録は日中フィードが続く期間に限られる（「開始の定義」参照）。
- **最終判定**: 開始から **12 か月時点**で、その時点で完了している全イベントについて同じ集計を行い、結論を出す。単元額（エントリー価格 × 100 株）の分布と中央値も必ず併記する。
- **結論の規則（固定）**: 最終判定で、判定主軸の集計について次の全てを満たす場合に「本実験の主張を前方データが支持した」とする。
  1. 平均損益率がプラス。
  2. TOPIX 超過リターンの平均がプラス。
  3. 中央値が −0.50% 以上。
  4. 実行不能率が **50% 以下**。

  1・2 の片方のみプラスは「部分的に支持」、1・2 ともマイナスは「支持しない」。3 または 4 を満たさない場合は、1・2 がプラスでも「支持しない（理由: 尾部依存 / 実行不能率）」とする。閾値・集計対象は結果を見て変更しない。
- **開始の定義**: 開始日は **2026-11-16**、前場レンジを観測するスナップショット（平日 11:37）と台帳の実装が完了し、フォワードのステップに組み込まれた最初の営業日とする。開始日以前のイベントは数えない（遡及エントリーはしない）。レンジの観測には J-Quants 分足アドオン（Tick+OhlcMin）を使うため、アドオンが終了する **2026-12-14** を過ぎると記録は停止する（フィードが途絶えた期間のイベントは欠測として扱い、後からの再構成はしない。代替データで継続することもしない）。記録の再開は、kabu 中継等のライブ日中フィードが実接続できた時点でメイン側が判断する。台帳に残った未決済イベントの決済は、記録停止後も通常どおり続ける。

- **方向の非対称**: 「前提データ」に明記の通り、効果は主に陽線日の翌日反動に宿り、陰線の部分集合は前半がマイナスである。登録する形は方向で条件付けしない pooled のまま固定し、結果を見て条件付けはしない（絞る場合は別実験として起草する）。
- **半期・年次の非対称**: 後半が前半の約4倍強く、強さは直近年（2026年 +1.279%）に寄っている。記述期間が2年しかないことと合わせ、レジーム依存の可能性を割引として明記する。
- **ショートの尾部**: 最悪単一は −39.40%（前半）/ −34.40%（後半）。連続ストップ高などで翌日引けの買い戻し自体が困難になり得る（繰り延べ規則はこのためのもの）。保有中の損切りは組み込まれていない。想定元本 ¥20,000/件は記録単位であり、実弾化の際は1件あたり損失上限を別途設計しなければこの形では扱えない。
- **逆日歩の未計上**: 一晩保有のため逆日歩は実際に発生し得るが、取得手段が無いため記録は「取得不可」とし、実績コスト後から差し引いていない。判定主軸の数字はこの分だけ楽観側である。特に値幅の広い銘柄は逆日歩の発生しやすい銘柄群でもあり、この留保は本実験では軽くない。
- **日中フィードへの依存と記録の停止**: 信号の観測には前場の分足が要る。J-Quants 分足アドオンは 2026-12-14 で終了するため、それ以降の前方記録は kabu 中継等のライブフィードが前提になる。フィードが途絶えた期間のイベントは記録されず、欠測として扱う（後からの再構成はしない）。このため最終判定（開始から12か月）の集計は、記録できた期間のイベントのみに基づく。
- **イベントの非独立性**: 値幅の広い日は地合い全体の変動日に集中し、イベント同士は強く相関する。名目件数に対する実質的な独立サンプル数はこれより小さい。
- **機構の混合**: レンジ拡大の原因（実情報への反応か、流動性の一時的な枯渇か）は区別せず一括で測る。イベント日の開示有無を台帳の観測項目に残す（判定には使わない）。
