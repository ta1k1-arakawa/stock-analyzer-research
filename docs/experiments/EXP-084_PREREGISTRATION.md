# EXP-084 事前登録：任意開示の「厚み減少」側の非対称テスト（第10弾 候補4）

根拠（内部証拠）：EXP-054/055 で「開示行動の遅い状態変数は再現する」
ことが示されたが、使ったのは増加側（dVolA ≥ 2 への +0.10 ボーナス）
だけである。減少側は未検証。本実験は同じデータ・窓・ソフトさで
符号だけを反転させる。054 の材料の再利用であり、多重検定の割引は
最大級にかかることを明記する。

## 定義

EXP-054 の dVolA（任意開示件数の対前年12か月差）をそのまま使い、
dVolA ≤ −2 の銘柄にロング側 tilt へ −0.10 のペナルティを与える
（スコア = A の傾斜スコア − 0.10、該当銘柄のみ）。ショート側は不変
（EXP-031/042 の教訓：ショート側スクリーンは逆効果）。

## キルルール（記述段階）

減少フラグ銘柄の同時点中央値が 8 銘柄未満、または減少銘柄の翌20営業日
TOPIX 超過リターンの符号が前半・後半でそろわなければキル。

## 判定基準（標準3基準、対 A）

1. 前半・後半とも base コストで利益がプラス
2. 前半・後半とも 年率/DD 比率が A を上回る
3. 全期間 stress で利益がプラス、かつ比率が A を上回る
