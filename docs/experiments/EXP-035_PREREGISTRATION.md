# EXP-035 事前登録:A のショート比率を 0.5 から 0.75 に上げる

状態: 計画(未実行)

## 背景・仮説

DD 診断(2026-11-01)の帰結。A の主要ドローダウン6局面のうち4つは市場暴落型で、ロング側は TOPIX 以上に下落し(ベータ約 1.2–1.45)、ショート側は毎回利益を出したが 0.5 倍では相殺しきれなかった。ショート比率そのものは EXP-009 で 0.5 に置かれて以来、一度も振っていない未検証の構成パラメータである。比率を 0.75 に上げれば暴落局面のクッションが厚くなり、DD が浅くなる可能性がある。

## 設計(固定)

- 対象は A そのもの(選択・スコアは一切変えない)。**A_s75 = A のロング 1.0 / ショート 0.75**
- 振るのはこの1案だけ。0.6・0.9・1.0 など他の値は試さない(パラメータ・マイニングの回避)
- 比較対象は A(0.5)。期間・費用(基本/ストレス、キャリーはショート想定額に比例して増える)は従来どおり

## 判定基準(A に対する通常の3基準)

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

## リスク・注意(結果を見る前に)

- 代償は構造的:上昇相場ではショートの逆風が 1.5 倍になり、キャリー(基本 3%/年、ストレス 5%/年)も増える。後半(上昇局面)の比率が下がる可能性が高い
- 残り2つの局面(2021年秋・2026年春のファクター冬)は市場無風型で、この変更では直らない
- 「有望」になればライブの A の構成変更が論点になるが、それは別の承認事項であり、本実験の判定と混ぜない
