# EXP-106 事前登録: 一過性損益に汚染された予想修正の減衰（自己発掘 第11弾）

登録日: 2026-11-08（実行前に push する）。常駐指示（2026-11-08）に基づき、通過した場合はユーザーの追加承認なしにフォワード・ペーパー統合まで進める。ライブA・実弾Vは変更しない。

## 仮説

特別利益・特別損失・減損の開示を伴う業績予想の修正は、本業の収益力の変化ではなく一過性要因の反映であることが多い。現行のAは修正モメンタム（過去90日の修正符号の集計）にそうした修正を通常の修正と同等に数えており、信号が汚れている。一過性開示に近い修正を集計から除けば、モメンタムの質が上がる。

## 実現可能性（登録前に確認済み）

TDnetタイトル履歴（2016-10-01〜2026-09-30、306銘柄）で、業績予想の修正・差異イベント2,159件のうち345件（16.0%）が、同一銘柄の特別利益・特別損失・減損タイトルの±7暦日以内にあった。介入の大きさとして十分。

## 構成

- フラグ: TDnet日次タイトル一覧から、コードごとに一過性タイトル（特別利益|特別損失|減損）の日付集合を作る。キャッシュ fins の修正レコード（E10のモメンタムが使う修正イベント）のうち、同一コードの一過性タイトルが±7暦日以内にあるものを「汚染された修正」とする。
- クリーンモメンタム: E10.revision_momentum_scores と同じ手順（直近90日の修正符号のパーセンタイルランク）だが、汚染された修正を符号集計から除外して再計算する。
- スコア A_oo = (comp_r + cleaned_mom_r) / 2。それ以外（本の仕組み、ショート比率0.5、コスト）はAと同一。

- タイトルベースのフラグは近似である（金額の大きさは履歴では分からない）。抱き合わせ開示（特別損失の計上「及び」業績予想の修正）は同一文書でも別タイトル行になる場合があり、±7日の窓で拾う設計。
