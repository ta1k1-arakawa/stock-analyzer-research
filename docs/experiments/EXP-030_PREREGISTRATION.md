# EXP-030 事前登録：株主還元利回り（配当利回り＋自社株買い利回り）の水準ティルト

状態: 計画（未実行）。必要フィールドの存在はキャッシュで確認済み

## 背景・仮説

文献探索（2026-10-31）の第2案。株主還元の「水準」が高い銘柄（予想配当利回り＋自社株買いによる株式数の減少率）への優遇は、米国では配当・自社株買いの合計利回りがバリュー指標として機能し、日本でも還元強化の流れが続いている。EXP-025 が還元の「変化（増配イベント）」だったのに対し、本案は「水準」を見る点が異なる。データはすべて J-Quants Standard の財務サマリー（キャッシュ）で足りる。

## シグナル（すべてこの事前登録で固定する）

開示レコード（EXP-025 と同じ FY 規約: 本決算は NxF*、それ以外は F*）から、時点 d で利用可能な最新の値を使う:

- **配当利回り** = 年間配当予想（FDivAnn / NxFDivAnn） ÷ 終値(d)
- **自社株買い利回り** = −（純株式数の前年比 − 1）。純株式数 = ShOutFY − TrShFY（TrShFY が無ければ ShOutFY のみ）。連続する2つの異なる ShOutFY 観測の比で測る
- **TSY = 配当利回り + 自社株買い利回り**（買い戻し側はマイナス＝希薄化もありうる）
- 配当予想が無い銘柄は TSY 欠損として中立 0.5。株式数のペアがまだ無い銘柄は自社株買い成分を 0 とする
- レッグ: A の有効集合の中で TSY を日次パーセントランク化
- **A_tsy = (comp_r + mom_r + tsy_r) / 3**。比較対象は A（S も併記）。期間・費用は従来通り

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- 配当利回りの水準は B/P や予想ROE と相関しやすく、複合スコアとの重なりで増分が薄い可能性がある
- 自社株買い利回りは年次の株式数変化で測るため、実際の買い戻し発表のタイミングとはずれる（発表そのものは TDnet 領域であり、本案はあくまで水準の代理）
- 事前の見立ては EXP-025 型（損益は互角でも DD で落ちる）の可能性が高い。それでも水準と変化は別の仮説として検証する価値がある
