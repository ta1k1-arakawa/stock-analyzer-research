# EXP-021 事前登録：ユニバース拡大（約800銘柄）での S／A の再検証

```text
author=Muse（ユーザー依頼：7候補終了後の新規候補群の1つとして承認）
data=J-Quants API v2（ユーザーの Standard 契約）で新規取得する広ユニバース・キャッシュ
code=experiments/exp021_fetch.py / experiments/exp021_wide_revalidation.py（この事前登録の後に作成）
```

## 背景

- 全実験のユニバースは 306 銘柄で固定されてきた。Gu–Kelly–Xiu の教訓では予測シグナルの収益化は銘柄数（breadth）に強く依存し、306 という狭さ自体が A やリッジの天井になっている可能性がある
- 本実験は新しいシグナルを試すのではなく、**土台を広げたら既存の勝者 A（と物差しの S）の成績がどう変わるか**を測る。業種コードも同時に取得し、将来の実験（業種中立化など）の土台にする

## ユニバース定義（固定。結果を見て変えない）

- 取得時点で J-Quants の銘柄情報（/v2/equities/master）に載る、市場区分がプライムの普通株式
- そのうち EXP-002 と同じ流動性条件（直近20営業日の平均売買代金 ≥ ¥100,000,000 を満たす日が評価期間の過半にある銘柄。EXP-003 の適格条件と同一の考え方）を満たし、かつ価格履歴が 2016-10-31 以降ある銘柄を評価対象とする。上限は設けない（想定 700〜900 銘柄）
- **生存バイアスの留保**: ユニバースは取得時点の上場銘柄で定義するため、期間中に上場廃止になった銘柄を含まない。EXP-002 の 306 銘柄も同じ性質を持つため相対比較は可能だが、絶対水準は楽観側に寄りうる。この留保は結果文書にも明記する

## 取得するデータ

- 日次株価（/v2/equities/bars/daily、2016-10-31..取得日）、財務サマリー（/v2/fins/summary、全期間）、TOPIX（/v2/indices/bars/daily/topix）。EXP-002 と同じキャッシュ形式（bars/・fins/・topix.json）で別ディレクトリに保存する
- 銘柄情報（コード・市場・17業種コード・33業種コード）を universe.json として保存する

## 検証方法

- 広キャッシュ上で S と A を EXP-009／010 と同一のエンジン・費用・期間で再計算する
- **健全性チェック**: 広ユニバースのうち元の 306 銘柄だけに絞った計算が、EXP-002 キャッシュ上の S／A と一致すること（データ取得の差異があれば数値で報告する。J-Quants の過去データ改訂により完全一致しない場合は、その差を結果文書に記録したうえで広ユニバース同士の比較に進む）

## 判定（広ユニバース内での A vs S）

1. 前半・後半とも A の基本損益 > 0
2. 前半・後半とも A の比率が S より大きい
3. 全期間ストレスでも A の損益 > 0 かつ比率が S より大きい

を満たせば「拡大ユニバースでも A の優位は維持」と結論する。加えて、A の絶対成績（損益・比率・DD）が 306 銘柄時とどう変わったかを報告する（拡大の効果そのものの評価）。

## 最大のリスク

- 生存バイアス（上記）。特に後半の絶対成績は割り引いて読む必要がある
- 取得は数時間規模になりうる（API のページングとレート制限）。再開可能な取得スクリプトで実行する
- 広げた分だけ流動性の低い銘柄が混ざり、想定スリッページ（基本 0.03%）が楽観的になる可能性がある。ストレス費用（0.10%）の結果も併記する
