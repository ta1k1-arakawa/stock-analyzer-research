# EXP-093 事前登録：売上高予想の「癖」— 予想の信用を3つ目の道具で測る

根拠：EXP-080（純利益予想の癖）は通過し、EXP-092（配当予想の癖）は
材料不足で落ちた。売上高予想は全社が開示し観測数が最も多い。
癖の測定が「予想の信用」という一貫した性質を捉えているなら、
売上でも効くはずである。

## 定義（EXP-092 と同じ骨格、物差しだけ売上用）

- 翌期の初期売上予想 = FY 短信の NxFSales、その期の実績 = 翌年 FY
  短信の Sales（> 0 の場合のみ）。
- 年次バイアス = (初期予想 − 実績) / 実績、±0.5 で winsorize
  （売上は利益よりブレが小さいため）。
- habit = 直近3期分の平均（2期以上必要）。
- エピソード窓：FY 短信の開示日から、その売上予想（FSales）が
  変更される次の開示、または3か月の早い方。
- 窓の間、habit > +0.03 の銘柄にロング側 −0.10。ショート側は不変。

## ゲートと判定

ペナルティ対象の同時点中央値が 5 銘柄未満なら材料不足として記録。
判定は標準3基準（対 A）。
