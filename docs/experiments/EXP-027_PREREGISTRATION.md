# EXP-027 事前登録：修正レッグの拡張（複数ラインのブレッドス＋整合性）

状態: 計画（未実行）

## 背景・仮説

文献探索（2026-10-31）の第4案。A の修正モメンタムレッグは純利益予想だけを見る。これを売上・営業利益・純利益の3ラインに広げ、ライン間の整合性を条件に加える。根拠: (1) 複数ラインが同じ方向に動く修正は情報量が多く、持続しやすい。(2) 純利益だけが上・営業利益が下のような修正は、持分売却益や税効果など一過性要因の可能性が高く、割り引くべきだという会計上の整合性の考え方。これは新しいリターン源泉の追加ではなく、全実験で唯一「有望」を取ったレッグ自体の質の改善であり、追加データも不要。

## 定義（EXP-010 のイベント抽出をそのまま一般化する）

- 予想値の選択規約は EXP-003/010 と同一（FY 決算短信は NxF*、それ以外は F*）を、Sales / OP / NP の3ラインに適用する
- 銘柄ごとに開示を (DiscDate, DiscTime) 順に並べ、連続する開示ペアごとにライン別に sign(今回値 − 前回値) を取る（両値が存在するラインのみ。欠けたラインは寄与 0）
- **ステップスコア** = 3ラインの sign の合計。ただし sign(NP) と sign(OP) が両方とも非ゼロで逆向きの場合、その2ラインは相殺して 0 とし、Sales の sign だけが残る（整合性ルール）
- レッグ値 = 開示日が (d−90日, d] に入るステップスコアの合計（EXP-010 と同じ90日暦日窓）。日次で百分位ランク化する
- **A_br = (comp_r + breadth_r) / 2**（A の有効集合上。NP 単独レッグを置き換える）
- バリアントは1本のみ。比較対象は A（S も併記）。期間・費用は従来通り

## 判定基準（A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たせば「有望」。

## リスク・注意（結果を見る前に）

- ブレッドスの学術的裏付けはアナリスト予想ベース（米国・グローバル）が中心で、日本の会社予想での直接検証は見つかっていない
- 3ライン化でイベント総量は増えるが、ライン間相関が高ければ実質 NP レッグとほぼ同じになり、差が出ない可能性
- 整合性ルールは「一過性は逆行する」という仮定に依存する。持分売却益のような一過性の上方修正がそのまま株価に織り込まれる局面では裏目に出る
