## データとゲート

- EDINET API v2 から有価証券報告書（120）＋訂正（130）を 3,116 件取得し、GPA を 2,720 行（268銘柄）抽出（data/edinet_exp012/gpa.csv、SHA-256 は manifest.json に記録）
- カバレッジゲート（中央値の日の GPA 保有率 ≥ 60%）：**83.3% で通過**（2017年中央値 69.9%、2026年 87.3%）。適格セルに GPA がある割合は 79.1%
- データ処理ルール（結果を見る前にユーザー承認済み、2026-10-30）: ①doc_id で重複除去（再開時の再処理で生じた完全重複 24 件）②銘柄ごとに提出日時が最新の GPA を採用（訂正 130 は期日が空欄のため、期日キーではなく提出日時で上書き。実際に値が変わる訂正は 8 件）③欠損は中立 0.5

## 解釈（結果を見た後の考察。基準の変更はしない）

- GPA 脚は後半（2022年以降）では A・B ともに S を大きく上回ったが、前半（2017–2021年）で崩れた。特に A の前半は比率 0.012・最大DD −36% と、S より深いドローダウンを伴った
- 前半で弱い一因として、EDINET の有報は決算短信より数か月遅れて GPA が届くこと、前半初期は10年間の閲覧期限切れでカバレッジが薄いこと（2017年 69.9%）が考えられる。ただしこれは事後の説明であり、定義を変えての再判定はしない
- 帰結: GPA は予想ROEの代替にもブレンド相手にもならなかった（この期間・この定義では）。候補2はここで終了し、次は候補3（ボラティリティ管理型）に進む

## 逸脱と注記

- 取得は VM の再起動で2回中断し、その都度チェックポイントから再開した（欠落なし）。仕分け処理のバグ（periodEnd が null の書類での並べ替えエラー）を1回修正した。いずれもデータ内容・実験定義には影響なし
- EDINET の書類は開示から約10年で閲覧期限が切れるため、2016年の有報は一部取得できない（最古の提出は 2016-11-18）。これは EDINET 版の既知の制約として事前に受け入れたもの
