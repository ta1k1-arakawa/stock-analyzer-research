# EXP-042 事前登録:空売り残高報告(大口公表ポジション)の集計 — ガードと変化ティルト

状態: 計画(未実行)。データ取得は完了(J-Quants Standard /v2/markets/short-sale-report、306 銘柄で 106,093 件、少なくとも 1 件ある銘柄 256、報告者キー 165)

## 背景・仮説

文献探索第3弾の第3案。発行済株式の 0.5% 以上の空売りポジションは公表が義務付けられており、大口の機関投資家の空売りは情報を持つとされる(米国の short interest 文献)。日本では残高の「水準」については実務家の反証があるため、本実験は (a) 踏み上げ回避のガード、(b) 残高の「変化」の 2 形態で検証する。なお EXP-031 の信用売り残(週次)による空売り側除外は逆効果だった。データ源は異なる(大口公表 vs 信用取引)が、同系統の設計への反証として明記する。

## 集計方法(この事前登録で固定する)

- レコードは全項目一致の重複を除去する(仕様上、重複が存在する)
- 報告者キー = (SSName, DICName, FundName)。(銘柄, 報告者) ごとに (CalcDate, DiscDate) 順の最新報告を現在値とし、**公表日(DiscDate)から利用可能**とする
- **agg(銘柄, 日) = 直近 365 日以内に報告のある報告者について、最新比率(ShrtPosToSO)の合計**。365 日を超えて音信のない報告者は解消したものとして除外する(判断の固定)
- 報告が一切ない銘柄は agg = 0 とする

## 変種(各々を A と比較し、通常の3基準で判定)

- **A_g1(ガード)**: ロング側は A のまま。ショート側では、その日の agg > 0 の銘柄の中での 90 パーセンタイル以上に当たる銘柄をショート候補から除外する(EXP-013 の simulate2 で実装)
- **A_chg(変化ティルト)**: Δagg = agg − 20 取引日前の agg。ロング側スコア = (複合順位 + モメンタム順位 + rank(−Δagg)) / 3、ショート側スコア = (複合順位 + モメンタム順位 + rank(+Δagg)) / 3(増えた銘柄を売り、減った銘柄を買う)

## リスク・注意(結果を見る前に)

- 公表制度上、0.5% 未満のポジションは見えない。「報告なし = 空売りなし」ではない
- 報告件数は年々増えており(2017 年 7,685 件 → 2025 年 15,818 件)、シグナルの意味が時期で変わりうる。順位・パーセンタイル化はその吸収を狙うが完全ではない
- ガードが実際に効くのは残高のある少数の銘柄に限られ、本全体への影響は小さい可能性が高い
