# EXP-081 計画：EXP-080（予想の癖による割引）のフォワード統合（ペーパー AF）

EXP-080 が標準3基準を全て通過した（4例目）。ただし EXP-046/052 の先例どおり、
バックテストの通過はライブ採用を意味しない。本計画は EXP-047/053/055 と
同じ手順で、A_fc をペーパーポートフォリオ **AF** としてフォワードに追加し、
まず再現検証で相対優位がフォワード実行系でも再現するかを確認する。

## 統合内容（exp004_forward.py）

- PORTFOLIOS に "AF" を追加。初期状態は R の pending を複写（従来パターン）。
- step のランク構築で、その日時点で初期予想窓に入っている銘柄について
  EXP-080 と同一のエピソード計算（fins 全履歴から habit を point-in-time に
  計算）を行い、予想を (1+habit) で割った複合スコアから A_fc の傾斜スコアを
  作る。ロング側は赤字回避銘柄を除外（rank["AF"])、ショート側は除外なしの
  A_fc スコア（rank["AF_s"]）に従う。バックテストの simulate2 と同じ非対称。
- ライブ A と実弾 V は変更しない。

## 再現検証（2022-01-04〜2026-09-25、EXP-011 ハーネス）

- チェック1（参考）: リプレイ A の利益がスケール換算したバックテスト A
  （後半 +¥4,160,686 × 400,000/2,000,000 = +¥832,137）の ±5% 以内か。
  過去3回とも +8.1% で外れた既知のパターン（フォワードは系統的に熱い）。
- チェック2（本命）: リプレイ AF/A 利益比がバックテスト後半の比
  （4,974,308 / 4,160,686 = 1.1955）の ±10% 以内か。相対優位の再現が判定軸。

## 判定

チェック2 が通れば AF は「再現した挑戦者」として AV と同列に置き、ライブの
実績が最終裁定する。落ちれば AR/AA と同列（ペーパーのまま観察）。いずれも
ライブ A・V は変えない。

## 修正記録（2026-11-03、実装のみ・仮説と判定基準は不変）

初回リプレイで AF が A と完全一致し続けたため調査したところ、フォワードの
fundamentals.csv には実績 NP と売上高の列自体が無く（予想と純資産のみ）、
habit が一切計算できず AF が A にフォールバックしていた。データ基盤側の
不足であり、戦略の定義の問題ではない。対処:
- free_data.py の TDnet XBRL 抽出に実績 NP・売上高を追加（今後の開示分）。
- fundamentals.csv に両列を EXP-002 キャッシュ＋J-Quants API で遡及入力。
- リプレイは修正後に最初からやり直す。
