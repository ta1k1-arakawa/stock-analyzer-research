# EXP-040 事前登録:決算発表の遅延化ティルト

状態: 計画(未実行)

## 背景・仮説

文献探索第3弾の第1案。決算発表のタイミング自体が情報を持つ:悪いニュースほど発表が遅れる傾向があり、例年より遅れて発表した銘柄はその後もアンダーパフォームする(Penman 1984/1987、米国。「延期」発表のイベント研究でも大幅な下落が報告される)。市場はタイミングに埋め込まれたシグナルに十分反応しない、というのが機序である。日本の効果量は未確認であり、本実験はその検証でもある。

## シグナル定義(この事前登録で固定する)

- J-Quants 財務サマリの決算開示レコード(CurPerType ∈ {FY, 1Q, 2Q, 3Q})について、同銘柄・同期間区分の前年レコード(開示日の差が 300〜400 日)がある場合に **delay = 開示日ギャップ − 365 日** を測る
- 日次では、各銘柄の直近の開示(開示日 ≤ 評価日)で測れた delay を持ち回る(失効なし)。leg = −delay(早い発表ほど高スコア)
- A の有効集合内で leg を順位化し、**A_delay = (複合順位 + リビジョン・モメンタム順位 + leg 順位) / 3**。leg の無い銘柄は中立 0.5
- データ実測(登録前の確認): 決算レコード 14,386 件中、前年マッチは 9,645 件(67%、残りは主にパネル初年度と決算期変更)。delay の分布は中央値 0 日、p10 −5 日、p90 +4 日で、+7 日超の遅延は 1.7% と裾は薄い。効果があっても小さい可能性が高いことを明記する

## 判定基準(A に対する通常の3基準)

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

## リスク・注意(結果を見る前に)

- **時期の汚染**: 2020 年は取引所の特例で延期が「正常な理由」で大量発生した年であり、シグナルがノイズ化している可能性が高い(前半に含まれる)。特段の除外はしない
- 予定日データは使わない(当初予定が残るか未確認のため)。本定義は「前年実績比」で測る実績ベースであり、発表「前」に遅延を検知する設計ではない — Penman のうち発表後ドリフトの部分だけを検証する
- 日本の開示は年々早期化しており(平均 −1.8 日)、「相対的な遅れ」の意味が時期で変わりうる。順位化はその影響を部分的に吸収する
