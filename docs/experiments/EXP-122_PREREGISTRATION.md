## 仮説

決算短信について、数値サプライズ指数（SUE）と LLM が短信テキストから抽出したテキスト・サプライズ指数（LES）は、単独では決算後ドリフト（PEAD）を生まない。しかし両者が不一致の場合、特に「SUE 高位 × LES 低位」（数値は強いのに文章は弱い）のセルでは、市場の初期反応がテキストに引きずられて数値と逆方向に出た後、価格が数値サプライズの符号方向へ修正されていく。種村・久保・中川（人工知能学会 金融情報学研究会 SIG-FIN-035-26、2025）は、TDnet 全上場・2023-01〜2024-12 の決算短信でこのセルに初期反応 CAR(0O,1O) = −1.26%（有意）の後のドリフト CAR(1O,5C) = **+0.69%（有意）** を報告し、対照セル（LES高 × SUE高）では初期反応 +1.24% の後に −0.55% の反転を報告した。著者らの解釈は、テキスト情報は初期反応で（過剰に）織り込まれ、数値情報の含意への修正がその後のドリフトとして現れる、というものである。本実験はその前方検証として設計する。

## 信号の固定

- **ユニバース**: 我々の 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）。
- **イベント**: ユニバース銘柄の四半期決算発表（決算短信）。発表の特定は fundamentals.csv に当該四半期の新規行が載ったこと（disc_date = 発表日）とし、本文は TDnet 本文アーカイブの当該短信 PDF を用いる。1回の発表を1イベントとし、同一銘柄・同一四半期の再掲・訂正は初回の発表のみをイベントとする（訂正によるエントリー取消はしない）。
- **SUE（数値サプライズ、固定定義）**: 単四半期 EPS を「当期累計の親会社帰属純利益 − 同一会計年度内の前期までの累計」を発表時点の shares_out で割って得る（1Q は累計そのもの）。
  - SUE = (EPS_t − EPS_{t−4}) / σ̂。σ̂ は当該銘柄の季節差分（EPS_s − EPS_{s−4}）の直近8個の標準偏差（標本標準偏差、ddof=1）。季節差分8個が揃わないイベントは「算出不能」として記録のみ（エントリーしない）。
  - 分位化: 2016–2022 年の当方 fundamentals 履歴（306 ユニバース全イベント）における SUE 分布から、目標配分 **10/20/40/20/10%** の等分位点を境界として登録時に一度だけ算出・凍結する。以後は再計算しない。Q1〜Q5 の帰属はこの固定境界による。
- **LES（テキスト・サプライズ、固定定義）**: 発表当日の夜（本文アーカイブ完了後、翌営業日の寄付まで）に、当該短信の **タイトル＋本文テキスト全体**（pypdf で抽出。企業名・銘柄コード・発表日時などのメタ情報は入力に付加しない。本文中に含まれる社名等の扱いは原論文と同様、加工しない）を、付属の固定プロンプト（原論文 図1 の再構成、付録A）で採点し、1（強いネガティブ）〜5（強いポジティブ）の整数スコアと理由（200字以内）を得る。
  - 採点は1イベントにつき1回限りとし、再採点・上書きはしない。採点に使う LLM のモデル名、プロンプト版、生出力を台帳に記録する。
  - 本文 PDF がアーカイブに無い、テキスト抽出に失敗した、または採点が完了しなかったイベントは「採点不能」として記録のみ（エントリーしない）。
- **主セル（エントリー対象）**: SUE が Q4∪Q5（高）**かつ** LES が 1 または 2（低）。買いのみ。
- **副次観測（記録のみ、判定に使わない）**: 逆セル（SUE が Q1∪Q2 かつ LES が 4 または 5）については空売りの仮想損益を記録する。また主セル・逆セルとも、20 営業日・60 営業日の保有リターンを参考記録する（原論文の実測窓は (1O, 5C) のみであり、これらは判定に使わない）。

## エントリー / エグジット

- **エントリー**: 発表日の**翌営業日の寄付**で買う。発表日が非営業日の場合は次の営業日を発表日相当として扱う。SUE の算出に必要な当該四半期行が発表当日の update-data 時点で fundamentals に載っていないイベントは「データ未達」として記録のみ（エントリーしない）。
- **エグジット**: **発表日から5営業日目の営業日の引け**で売る（原論文のドリフト窓 (1O, 5C) に対応）。売却日に引け値がつかない場合は、価格がつく最初の後続営業日の引けに繰り延べる。上場廃止等で価格が得られない場合は、最後に得られた終値で異常終了として記録する。
- **価格**: 株数の決定には未調整寄付を用いる。損益率は未調整の寄付→引けの比率を主とし、保有期間中に株式分割・併合があったイベントでは調整済みベースの比率を正として併記する（両価格とも台帳に残す）。
- **ベンチマーク**: 各イベントについて、エントリー寄付からエグジット引けまでの TOPIX の変化率を同一窓で記録し、超過リターンはイベント損益率からこれを差し引いたものとする。
