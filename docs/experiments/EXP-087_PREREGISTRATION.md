# EXP-087 事前登録：効いた作戦の「用量」マップ（ユーザーの並行拡張指示、2026-11-05）

再現・通過した変更は3つだけ（AV ボーナス +0.10、AF の habit 割引、
ショート比率 0.75）で、いずれも用量は1点しか測っていない。用量反応を
知ることは、次の合成設計と、フォワードで観測すべきペーパーの選定に
直結する。各変種は標準3基準（対 A）で判定する。

- **087A**: AV ボーナスを +0.10 → **+0.20**（EXP-054 の他の条件は同一）。
- **087B**: AF の割引を habit × **1.5**（clip は EXP-080 と同一、
  除数 = 1 + 1.5 × clip(habit, −0.5, 1.0)）。他の条件は同一。
- **087C**: ショート比率 **0.625**（0.5 と 0.75 の中点）。スコアは A そのまま。

通過した変種は、EXP-082/086 と同じ手順（フォワードにペーパー追加＋
再演で登録条件を判定）に進める。不採用の変種も用量マップとして記録する。
