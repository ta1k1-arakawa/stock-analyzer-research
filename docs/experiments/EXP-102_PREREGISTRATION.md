# EXP-102 事前登録：新しい芽 4 本（ABD の用量マップ ×1、勝ち土台への ABD 合成 ×1、減少の段階化 ×1、予想の癖のショート側 ×1）

登録日: 2026-11-07（実行前に登録し、結果を見る前に push する）
背景: ユーザーの「どんどん種を増やしてください」（2026-11-07）を受けた
バッチ。EXP-100 の通過 3 本（AVF625・AV625・ABD）が再演でも両条件を
満たした直後であり、今回は (1) ABD の展開（用量・段階化・合成）、
(2) 一度も使っていない側（ショート側への予想の癖）への拡張、を行う。

共通の枠: EXP-002 キャッシュ、予算 ¥2,000,000、前半 2017-01-04〜2021-12-30、
後半 2022-01-04〜2026-09-25。S と A はスクリプト内で再計算し、公表値
（A: 前半 +¥1,001,487・比率 0.348、後半 +¥4,160,686・比率 1.605、
全期間 stress 比率 0.421）を正確に再現しなければ実行全体を無効とする。
内部照合として ABD（後半 +¥4,611,108・比率 1.678 = EXP-100D）と
AVF625（= EXP-100A の AVF15625、前半 0.452・後半 2.296）も再現すること。

標準 3 基準（対 A）: (1) base 損益が両半分とも > 0、(2) 年次/DD 比率が
両半分とも A を上回る、(3) 全期間 stress 損益 > 0 かつ比率が A を上回る。
適応基準（後半のみ、大量保有アーカイブが 2021-07 開始のため。EXP-052/088/098/100
と同じ枠）: (1) 後半 base 損益 > 0、(2) 後半比率が比較対象を上回る、
(3) 後半 stress 損益 > 0 かつ比率が比較対象を上回る。**適応基準の通過は
標準基準の通過より弱い判定であり、結果文書でも混同しない。**

## 102A — ABD625（ABD × ショート 0.625）

構成: EXP-100D の ABD スコア（A のロングに、type-2 で 1pt 以上の大量保有
減少イベント後 120 日間 −0.10、ショートは A）そのままに、ショート比率だけを
0.5 → 0.625 に変える。
根拠: 0.625 レバーは AV・AVF15 の両土台で DD を約 1pt 浅くし再演条件を
両方満たした（EXP-101）。ABD は再演で DD が A より 0.04pt しか浅くなく
（−19.16% vs −19.20%）、比率の伸びは利益側に寄っていたため、DD レバーの
乗り具合を見る用量マップの欠けた点。
判定: 適応 3 基準（対 A）。参考として ABD（0.5）も同一実行で出す。

## 102B — AVF625D（AVF625 ＋ ABD 減少ペナルティ）

構成: EXP-100A の AVF625 スコア（予想の癖 ×1.5＋任意開示 +0.10 のロング、
喪失回避はロング除外、ショートは AF15 スコア・比率 0.625）のロングに、
ABD の減少ペナルティ −0.10（イベント後 120 日）を重ねる。ショートは
AVF625 のまま（AF15 スコア、0.625）。
根拠: AVF625 は再演で全ペーパー最良の比率 2.155・最浅 DD −14.30% を出し、
ABD は別ファミリー（大量保有の退出情報）で再演条件を両方満たした。
異なるファミリー同士の合成として、勝ち土台に情報脚を 1 本だけ足す形。
比較対象: 土台である AVF625（EXP-100B の教訓 — 脚の増分価値は土台対比で
見る。対 A の数値は観測として併記する）。
判定: 適応 3 基準（対 AVF625、後半のみ。ABD 脚のデータ制約による）。
**最大のリスク（事前に明記）**: EXP-067/100B の教訓 — 合成は土台対比で
比率を落とす型が再現している。今回は「利益脚＋利益脚」ではなく
「勝ち土台＋リスク回避型のペナルティ脚」の合成だが、同じ失敗形が
最有力の代替仮説であることに変わりはない。

## 102C — ABDG（減少ペナルティの段階化）

構成: 減少ペナルティを EXP-098B（買い増し側の ABG）と同じ考え方で段階化する。
type-2 の減少幅が 3pt 以上（strong）→ ロング −0.20、1pt 以上 3pt 未満
（weak）→ −0.10。窓はイベント後 120 日、同一銘柄に両方が重なれば strong
優先（ペナルティは大きい方）。ショートは A。
根拠: 買い増し側では段階化（098B）が適応基準を通過し、再演でも条件 (ii)
を満たした（ただし再演利益は AB を下回った — AVG/ABG とも「段階化は土台への
利益の上積みになっていない」観測がある）。減少側でも「大きく抜ける動き」
ほど情報量が大きいかを見る。
判定: 適応 3 基準（対 A）。参考として ABD（一律 −0.10）も同一実行で出す。

## 102D — 予想の癖のショート側適用（ASH）

新しい仕組み（データは全期間あるため標準基準で判定する）。
構成: ロングは A のまま（スコア・除外なし）。ショート側だけを組み替える：
各日、A の有効銘柄集合（composite が有効な銘柄）の中で、
- a_r = A スコアの百分位ランク
- h = EXP-080 の「癖」: エピソード窓（期初の純利益予想が立つ FY 開示から、
  予想が変わる最初の開示または 3 か月後の早い方まで）の中では
  habit = 直近 3 事業年度の期初予想バイアスの平均（バイアスは ±2 で
  winsorise、habit は [−0.5, +1.0] に clip、2 年分未満は無し）。
  窓の外・履歴不足の銘柄は h = 0（中立）。
- h_r = h の百分位ランク（同点は平均ランク、pandas 既定）
- ショートスコア = (a_r + (1 − h_r)) / 2
エンジンはこのショートスコアの「下位」から通常どおりショートを選ぶ
（simulate2 の仕様）。つまり期初予想が恒常的に楽観的（h が大きい）な銘柄ほど
ショートスコアが下がり、ショートされやすくなる。配合は 50/50 の 1 形のみで、
結果を見て重みを変えない。
根拠: 「癖」はこれまでロング側でのみ使われてきた（EXP-080 の割り引きと
喪失回避除外はどちらもロング側）。恒常的に楽観的な会社予想は、定義上
未達に終わりやすい予想であり、ショート候補としての自然さがある。
またショート側の再設計は EXP-031/042 でいずれも不採用だった経緯があり、
価格・空売り残ではなく開示行動ベースの信号で挑む点が異なる。
判定: 標準 3 基準（対 A）。
**リスク（事前に明記）**: エピソード窓は年 1 回・最長 3 か月で、窓外は
全銘柄が h = 0 の同点になるため、年間の大半は A の順位に定数が加わる
だけでショート順位はほぼ A と同じになる（効果が薄い可能性）。
逆に窓内では順位が大きく動くため、その差が全期間の判定を分ける。
