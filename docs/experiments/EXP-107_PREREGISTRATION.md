# EXP-107 事前登録: 有報テキスト変化（Lazy Prices、第11弾 R11-3）

登録日: 2026-11-08（実行前に push する）。常駐指示（2026-11-08）に基づき、通過した場合はユーザーの追加承認なしにフォワード・ペーパー統合まで進める。ライブA・実弾Vは変更しない。

## 仮説

有価証券報告書の開示文を前年からほとんど書き換えない会社（「怠惰な開示」）は、その後の株価が相対的に堅調で、大きく書き換える会社はその後劣後する。Cohen–Malloy–Nguyen "Lazy Prices"（Journal of Finance, 2020）の米国証拠では、低変化側にプラス、高変化側にマイナスの超過リターンがあり、2026年の追試でもスプレッド年率約3%が残存した。日本では未検証。開示行動そのものを見る遅い・価格以外の信号であり、本プログラムで通過してきた信号（任意開示の厚み、予想の癖）と同型である。

前提となる記述ゲート（2026-11-08、第11弾ゲート1）は通過済み: ユニバース306銘柄の有報（DocTypeCode 120）カバレッジは期末年2017–2025で99.9%（ローカルの J-Quants EDINET アーカイブ、DocId付き）、リスク・MD&A両ブロックの抽出はサンプル580件で580/580、使用可能な連続年ペア518件。リスク欄の文字バイグラム Jaccard 類似度は中央値0.925・IQR 0.159・≥0.99が16.6%・<0.70が12.5%で、退化していない横断面のばらつきがある。

## 指標の固定（ゲートからの申し送りを受け、本登録で最終決定する）

- **主信号はリスク欄のみ**: `BusinessRisksTextBlock`（type-5 CSV の jpcrp030000-asr 内、名前空間を問わずローカル名で照合し、セクションごとに最長の値を採用。抽出手順はゲートの gate1_extract.py と同一）。
- **指標は文字バイグラム Jaccard（集合）**: 空白を全て除去したテキストの文字バイグラム集合について Jaccard 係数を取る（ゲートと同一の計算）。
- cosine（バイグラム頻度）は採用しない。ゲートで中央値0.994と定型バイグラムに支配され判別力が弱かったため。
- MD&A（`AnalysisOfFinancialPositionOperatingResultsAndCashFlowsTextBlock` 等）はスコアに入れない。ゲートで Jaccard 中央値0.625と変化が大きすぎ、「怠惰」の測定ではなく業績変動の写像になり得るため。MD&A類似度は結果文書で参考診断として併記するに留める。
- 文献ドラフト（第11弾レポート）はリスク・MD&A・全文の類似度を併記していたが、上記のとおりゲート所見に基づきリスク欄 Jaccard 一本に絞る。これは結果を見る前の変更であり、本登録をもって固定する。

## 構成（A の第3成分として追加する年次傾斜）

- ペア: 同一銘柄の連続する期末年（PerEn）の有報同士。前年・当年の両方のリスク欄が抽出できた場合にのみ、当年側の届出に類似度 sim を付ける。
- 有効化（ポイント・イン・タイム）: sim は当年側届出の**提出日の翌日以降**に初めて有効になる（提出日当日は使わない。先読み禁止）。各日 t の状態は「提出日 < t を満たす最新の届出の sim」とし、次の届出の sim が有効化されるまで持続する（固定の失効期間は設けない。有報は年次開示であり、状態は自然に最大で1年強の寿命になる）。リスク欄が抽出できずペアが計算できない届出では状態は更新されず、直前の状態が残る。
- 傾斜成分: 各日、Aの有効集合のうち状態を持つ銘柄について sim をパーセンタイルランク化し lp_r とする（類似度が高い＝変化が小さい銘柄ほど高いランク。タイは通常の平均ランク）。状態を持たない銘柄は中立0.5。
- スコア A_lp = (comp_r + mom_r + lp_r) / 3。ロング・ショートとも標準の simulate（Aと同一の仕組み、ショート比率0.5）。高類似度（低変化）がロング側に寄り、低類似度（高変化）がショート側に寄る。
- 制度変更による一斉改訂（サステナビリティ欄の新設等）への対処は、日次の横断面ランク化そのものが水準シフトを吸収する設計とし、年次ダミーの別途調整は入れない（本登録で固定）。

## データとカバレッジの留保

- 届出センサスはゲートの gate1_filings.json（2,921件、306銘柄、期末年2016–2026の提出分）をそのまま使う。全件の type-5 CSV zip を EDINET から取得する（実装計画は EXP-107_PLAN.md）。
- 使用可能ペアは全数で約2,600件規模の見込み（ゲート推計: 年あたり約290ペア）。
- **前半の立ち上がり**: 期末年2015の有報はローカルアーカイブ（2016-11開始）の範囲外が大半のため、2017年の提出分にはペアがほとんど付かない（ゲートサンプルで開始年2016のペアは8件のみ）。したがって2017年中は大半の銘柄が中立0.5で傾斜はほぼ不発、2018年の提出シーズン以降に全面有効化する。これは先読みを避ける以上避けられない制約であり、前半の検出力が実質4年分程度になることを留保する。**この留保をもって判定基準は変更しない（適応基準は使わない）。**

## リスク・留保

- 約58番目の挑戦者であり、多重検定の割引が強くかかる。薄いマージンの通過は偶然でも起こり得る前提で読む。
- 日本での検証例は存在しない（見つかっていない）。米国でも効果は原論文期の年率約7%から追試の約3%へ減衰しており、日本で同程度の大きさがある保証はない。年次信号の寄与は小さく、20銘柄トランシェの本の年率/DD比率を両半期で動かすには至らない可能性がある。
- 時代リスク: 制度変更による開示様式の一斉改訂が「高変化」に紛れる。日次ランク化で水準は吸収するが、決算月の違い等で改訂タイミングが銘柄ごとにずれる年は汚染が残り得る。
- 定型文の塊: ペアの16.6%が類似度 ≥0.99 で、ロング側上位はタイが多く判別が粗い。
- 高変化側には、事業再編やガバナンス改革など前向きな変化を大きく書き込む会社も含まれる。それをショートする側には通常の空売りリスク（借株コスト・踏み上げ）が伴う。
