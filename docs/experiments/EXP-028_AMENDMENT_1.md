# EXP-028 修正 1：最小分散ウェイトの適用単位（バスケット計算＋トランシェ内比率配分）

状態: 初回実行が無効だったための設計修正。有効な A_mv の数値はまだ存在せず、本修正は結果を見る前の変更である。2026-10-31 にユーザーが承認した。

## 何が起きたか

初回実行では A_mv が A と完全一致し、最小分散が一度も効いていなかった。原因は2つ:

1. このエンジンの本は「1トランシェ = 2銘柄 × 10トランシェ」で20銘柄を構成する（PER_TRANCHE = 2）。事前登録のウェイト計算はトランシェ単位を想定していた
2. ウェイトの上限 10% は20銘柄バスケット前提の値であり、2銘柄に適用するとクリップ→再正規化で常に 50/50 に潰れた

ゲート（等ウェイトで A を完全再現）は通過しており、エンジン複製自体は正しい。初回数値はテストとして無効であり破棄した。

## 修正後の方法（これ以外は事前登録どおり）

- 最小分散ウェイトは、その側の**ブック全体（20銘柄）**で計算する。ブックの構成は「他トランシェの保有銘柄 + 当該トランシェの購入候補」とし、20に満たない場合（開始直後）はスコア順位の次の銘柄で補う
- 共分散窓（120日）・縮小（0.5）・クリップ [0.02, 0.10] と2回の再正規化・フォールバック規則はバスケットに対して事前登録どおりに適用する
- 当該トランシェの購入は、候補2銘柄のバスケット内ウェイトの**比率**で現金を配分する（トランシェの総額は不変）。ショート側も同様
- 銘柄選択・保有期間・費用・判定基準は変更しない
