# EXP-031 事前登録：空売り側の再設計（踏み上げ回避と下方修正の重視）

状態: 計画（未実行）

## 背景・仮説

A の空売り側は、ロングと同じスコアの下位をそのまま使う「鏡像」であり、独立に設計されたことがない。0.5 倍の空売り本が上昇局面で DD の発生源になっている可能性がある。空売り固有の事情は2つある:

1. **踏み上げリスク**: 空売り残が多い銘柄は、好材料で一斉に買い戻され急騰しやすい。空売り候補から「空売りが溜まった銘柄」を外すのは、ロング側の混雑回避（EXP-026）とは逆向きの、空売り固有のリスク管理である
2. **下方修正の駆動力**: 下落の起点は予想の引き下げであることが多い。空売りの選択では複合スコア（割高さ）よりも修正モメンタム（下方修正）を重く見る方が、下落を捉えやすい可能性がある

## バリアント（すべてこの事前登録で固定する。エンジンは EXP-013 の simulate2、ロング側は A 不変）

- **A_s1（踏み上げ回避）**: 空売りスコアは A のまま。ただし信用空売り残 ÷ 発行済株式数（週次、公表ラグ +4 日、EXP-026 と同じ写像・データ）のランクが A の有効集合内で上位10%（>= 0.90）の銘柄を空売り候補から除外する
- **A_s2（下方修正の重視）**: 空売り選択のスコアを (comp_r + 2・mom_r) / 3 に変える（小さいほど空売り候補）。ロング側のスコアは A のまま

比較対象は A（S も併記）。空売り比率 0.5・保有 20 日・費用は従来通り。

## 判定基準（バリアントごとに、A に対する通常の3基準）

1. 基本費用で前半・後半とも黒字
2. 年率/DD 比率が前半・後半とも A 超え
3. 全期間ストレスで黒字かつ比率が A 超え

3つすべてを満たしたバリアントを「有望」とする。

## リスク・注意（結果を見る前に）

- 空売り残の多い銘柄は「皆が弱気」という情報でもあり、外すことで下落の取り分を逃す可能性もある（踏み上げ回避と情報のトレードオフ）
- A_s2 は下方修正への集中度を上げるため、V 字回復局面では空売りが踏まれやすくなる可能性がある
- 空売りには貸株料・逆日歩等の実務コストがあり、本検証の費用前提（年3%/5%）を超える場合がある。判定は従来の前提での相対比較として読むこと
