## 信号の固定

- **ユニバース**: 306 銘柄ユニバース（EXP-002 キャッシュの対象銘柄）で開始する。全市場への拡張は、中間集計で実績コスト後平均がプラスを維持している場合にのみ、本書への追記（amendment）として登録した上で行う。
- **イベントの定義**: 取引日 t について、10:00 の1分足終値 p1000 と 10:00 時点までのVWAP（= 当日寄り付きから10:00までの売買代金合計 ÷ 出来高合計、特徴量 vwap1000）について **p1000 / vwap1000 − 1 ≥ +0.02** を満たす銘柄・日をイベントとする。同一銘柄・同一日は最大1イベント。分割疑い日、出来高ゼロの日、p1000 または vwap1000 が得られない日は対象外。
- **エントリー**: **10:00 の1分足終値（p1000）で売る（ショート）**。前方実装では記述と同一の p1000 をエントリー価格として台帳に記録する（実フィードでの観測価格との乖離は観測項目として残してよいが、判定は p1000 ベースで固定する）。10:00 は場中時刻であり、前方実装には場中のライブ記録（分足アドオン終了後は kabu 中継が自然な供給源）が必要である。
- **エグジット**: **当日の引け**で全量を買い戻す。引け価格が得られない（売買停止等）場合は、引け価格が得られる最初の後続営業日に繰り延べ、その旨と逆日歩の実績を台帳に記録する。エグジットの変更はしない。
- **価格**: 損益率は未調整価格どうしの比率とする。当日中に株式分割・併合の効力が発生したイベントは、調整済み価格ベースの比率を正として併記する。
- **ベンチマーク**: 各イベントについて、同窓（10:00→当日引け）の TOPIX 変化率を記録し、超過リターン = イベント損益率 + 同窓 TOPIX 変化率（ショートのため）とする。同窓 TOPIX が取得できない場合は、寄付→引けの TOPIX 変化率で代用し、その旨を記録する。

4. **逆日歩の発生有無と金額**（保有は当日内で完結するため原則発生しない。買い戻しが翌営業日以降に繰り延べになった場合は実績を記録し、取得できない場合は「取得不可（unavailable）」と記録して差し引かない）。

**実行不能の定義と集計**: 1 で貸借銘柄でない、または 3 で p1000 が成立していないイベントは「実行不能」と分類する。集計は (i) 全イベント / (ii) 実行可能イベントのみ の2建てとし、**判定は (ii) を主とする**。実行不能率は中間・最終の両集計で必ず併記し、実現可能性が取得できなかったイベントは (ii) に含めず「不明」として別掲する。
